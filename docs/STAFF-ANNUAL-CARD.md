# การ์ดประจำปีสำหรับเจ้าหน้าที่ — จัดเลือกตั้งหนึ่งรอบต้องทำอะไรบ้าง

เอกสารนี้คือภาพรวมหน้าเดียวสำหรับเจ้าหน้าที่ผู้ดูแลระบบ ใช้คู่กับ
[STAFF-HANDBOOK.md](STAFF-HANDBOOK.md) (ติดตั้ง / อัปเดตระบบ / จัดการแอดมิน),
[DEPLOY-CHECKLIST-2026.md](DEPLOY-CHECKLIST-2026.md) (ฉบับละเอียดทีละข้อ)
และ [MAINTENANCE-RUNBOOK.md](MAINTENANCE-RUNBOOK.md) (คู่มือแก้ปัญหา)

## ก่อนเลือกตั้ง (เผื่อเวลา 1-2 สัปดาห์)

1. **เตรียมข้อมูลปีใหม่** — บนเครื่องที่มี repo และต่อ DB ได้:

   ```bash
   npm run preflight                          # เช็คความพร้อมปีใหม่
   npm run archive-year                       # เก็บผลปีที่แล้ว
   npm run import-students -- <ไฟล์รายชื่อ>    # นำเข้าผู้มีสิทธิ์
   ```

2. **ตั้งค่าในหน้า admin** (ไม่ต้องแก้โค้ด): วันเวลาเลือกตั้ง, ปีการศึกษา, ชื่องาน,
   ลิงก์แบบประเมิน และเลือก template หน้าตาเว็บของปีนั้น

3. **Key ceremony — 10 นาที ปีละครั้ง** ทำกับอาจารย์ที่ปรึกษาบนเครื่องที่ไว้ใจได้:

   ```bash
   node scripts/generate-election-keys.js
   ```

   ทำตามที่ script บอกบนจอ: พิมพ์ private key ลงกระดาษแบ่งเก็บสองคน
   (เจ้าหน้าที่ + อาจารย์) แล้ว copy สองบรรทัด env ไปวางบนเซิร์ฟเวอร์ — จบ
   กระดาษแผ่นนั้นจะถูกใช้ก็ต่อเมื่อมีข้อพิพาทต้องนับคะแนนใหม่เท่านั้น
   ถ้าหายผลเลือกตั้งไม่เสีย เสียแค่ความสามารถนับใหม่

4. **ส่งมอบสิทธิ์แอดมินให้กรรมการชุดใหม่** — ถอดชุดเก่า ตั้งชุดใหม่ แล้วเปลี่ยนรหัสกลาง
   (คนที่พ้นวาระยังจำรหัสเดิมได้ ต้องตัดทั้งสิทธิ์และรหัส):

   ```bash
   node scripts/admin.js --list
   node scripts/admin.js --revoke <รหัส นศ. ชุดเก่า>
   node scripts/admin.js --grant  <รหัส นศ. ชุดใหม่>
   node scripts/admin.js --rotate-password
   ```

   วิธีใช้ทั้งหมดอยู่ใน [STAFF-HANDBOOK.md](STAFF-HANDBOOK.md) §1

5. **กดปุ่ม "ตรวจความพร้อม" ในหน้า admin เป็นด่านสุดท้าย** — ระบบเช็คเอง 14 ข้อ
   แล้วบอกว่าอะไรยังไม่พร้อม เขียวหมดถึงเปิด

## วันเลือกตั้ง

ปกติไม่ต้องทำอะไร ระบบเปิด-ปิดตามเวลาเอง สิ่งที่ควรรู้:

- หน้า admin โชว์จำนวนผู้ใช้สิทธิ์แบบ real-time
- เกิดเหตุฉุกเฉินให้เปลี่ยนโหมดเป็น `PAUSE` ในหน้า admin — ระบบหยุดรับโหวตทันที
  แก้เสร็จค่อยสลับกลับ `AUTO`
- ปุ่มรีเซ็ตข้อมูลถูกล็อกอัตโนมัติระหว่างการโหวตเปิดอยู่ กดไม่ได้ ไม่ต้องกลัวมือลั่น

## หลังปิดหีบ

```bash
node scripts/reconcile-scores.js     # ตรวจว่าคะแนน-จำนวนบัตร-โซ่ ตรงกันทั้งสามทาง
```

ตรงกันแล้วจึงกด "เปิดเผยผล" ในหน้า admin → เมื่อผลนิ่งแล้วกด "รับรองผล"
(certify — ทำครั้งเดียว ย้อนไม่ได้) เป็นอันจบปี

## ถ้ามีปัญหา

ทุกอาการที่เคยเจอและวิธีแก้อยู่ใน [MAINTENANCE-RUNBOOK.md](MAINTENANCE-RUNBOOK.md)
ถ้ามีคนตั้งคำถามกับผลคะแนน: `node scripts/verify-ballot-chain.js` พิสูจน์ได้ทันทีว่า
บัตรไม่ถูกแก้ และกรณีถึงขั้นต้องนับใหม่ ให้ใช้กระดาษ private key กับ
`scripts/decrypt-recount.js` แบบ offline ต่อหน้ากรรมการ
