## §A ระบบร่วม (ใช้ทุกหน้า — ทำครั้งเดียวใน v2-R1 แล้ว propagate)

### A1 · เรขาคณิตของเทป (tape spine)
- Desktop ≥1024px: เทปกว้าง `clamp(480px, 42vw, 560px)` ยึด offset ซ้าย
  (`margin-left: max(20px, 8vw)`) — **ห้ามกึ่งกลาง**; ของ scatter อยู่ฝั่งขวา + ทับขอบเทป
  ≥24px เสมอ (overlap คือหัวใจ ไม่ทับ = กลับไปเป็น grid)
- ขอบเทปซ้าย-ขวา: เงา `receiptEdge` 1px + ริมกระดาษม้วนโค้งจางๆ (inset shadow บาง)
- ท่อนเทป (segment) คั่นด้วย **แถบรอยปรุเต็มกว้างเทป** (dash 6/6 แบบ .rc-perf เดิม)
  ทุกท่อนมีหัว mono จิ๋ว (`ท่อนที่ NN · SECTION NAME`) แบบบรรทัดหัวใบเสร็จจริง
- ปลายเทปล่างสุดทุกหน้า: **ขอบหยักฉีกตามปรุ** + บรรทัดปิด `◆ ◆ ◆ สิ้นสุดรายการ ◆ ◆ ◆`
- Mobile <768px: เทป full-width (margin 12px) — scatter ยุบเป็นของแทรกระหว่างท่อน
  (ไม่ float ทับ) เพื่อความสงบ; รอยปรุ/หัวท่อน/ปลายหยักคงครบ

### A2 · Dispenser (หัวเครื่องจ่าย — dock บนสุดของเทปทุกหน้า)
- แถบเครื่องสีink โค้งบน 12px + ช่องจ่าย (slot เงา inset) + ไฟ LED สถานะ:
  เขียวมิ้นต์=เปิดหีบ · เหลือง=ใกล้ปิด/รอเปิด · แดงจาง=ปิด/พัก (ผูก systemMode จริง —
  ไม่ใช่ตกแต่งลอย) + ป้าย mono `SAMO {n} · {PAGE NAME}` บนตัวเครื่อง
- หน้าที่เครื่อง "เพิ่งพิมพ์": ขอบบนของท่อนแรกโผล่จาก slot (margin-top ลบเล็กน้อย
  ใต้เครื่อง) — ตรรกะเดียวกับ printer ของ success

### A3 · Topbar "หัวโต๊ะ" (แทน hairline editorial — ฆ่า DNA Blossom จุดแรก)
- โลโก้: อยู่บน **ป้ายกระดาษเล็กเสียบคลิปหนีบ** (กระดาษ receipt + คลิปโลหะจิ๋วมุมซ้าย)
- Nav: ลิงก์ละใบเป็น **ต้นขั้วบัตร** (สี่เหลี่ยมมุมตัด + รอยปรุซ้าย) เรียงชิดกัน;
  หน้า active = ต้นขั้ว "ฉีกแล้ว" (ขอบปรุเปิด + พื้น accent 8% + ตัวอักษร accentDeep)
  hover = ต้นขั้วยกขึ้น 1px; ทุกใบ ≥44px tap target
- User chip = **บัตรคล้องคอ/พนักงาน** (มุมตัด + รูเจาะ grommet จิ๋วบนขอบ)
- มือถือ: burger เดิม แต่ sheet = กองต้นขั้วเรียงลง; **DOM/behaviour logic เดิมทั้งหมด
  ห้ามแตะ** (แก้ CSS + wrapper aria-hidden เท่านั้น)
- เส้นใต้ topbar: คงรอยปรุ (ของ R2.5) — เข้ากับภาษาต้นขั้ว

### A4 · แสง เงา วัสดุ (ยกระดับจาก R2.5)
- แสงบน-ซ้ายเดิม; เพิ่มชั้น **contact shadow** (เงาสั้นเข้ม 1-2px) ใต้ของทุกชิ้นที่
  "วางบนโต๊ะ" แยกจากเงาฟุ้ง — ของจะ "แตะพื้น" ไม่ลอย
- กระดาษทุกผืน: grain จางมาก (SVG feTurbulence data-URI ตัวเดียวใช้ซ้ำ, opacity
  ≤0.02, ปิดบนมือถือถ้า perf ตก) + มุมกระดาษ 2-4px คงเดิม
- หมึกพิมพ์บนเทป: หัว mono ทุกจุดให้ "หมึกซีดไม่เท่ากัน" เล็กน้อย (letter-spacing เดิม
  + text-shadow 0 0 .3px จาง) — ความ imperfect ของ thermal print

### A5 · หัวเรื่องแบบใหม่ (เลิก editorial headline ทุกหน้า — ฆ่า DNA Blossom จุดสอง)
- **ห้าม**: eyebrow mono + H1 ใหญ่ลอยบนพื้นโต๊ะ (แบบปัจจุบันทุกหน้า = แกรมมาร์ Blossom)
- **ใช้แทน**: ชื่อหน้าเป็น **ท่อนแรกที่พิมพ์บนเทป** — บรรทัด mono `SAMO {n} · {PAGE}`
  → ชื่อไทยใหญ่ (Chakra Petch 700) พิมพ์บนเทป → เส้นปรุปิดท่อน; ตราปั๊มวันที่จาง
  ประทับเฉียงมุมขวาของท่อนหัว (จาก receiptMeta — ห้าม hardcode)

### A6 · คลังของตกแต่ง (approved inventory — ห้ามคิดของใหม่นอกลิสต์โดยไม่ผ่าน Fable)
ต้นขั้วบัตร · คลิปหนีบ (ใหญ่/จิ๋ว) · หมุดโลหะ · เชือก+grommet · เทปใสโฮโล ·
ตราปั๊มวงแหวน (หมึก accent/แดง/เขียว/ส้ม semantic) · แท่นหมึกสตางค์ · ซีล foil ·
โน้ตมะนิลา · ใบเสร็จม้วนงอปลาย · barcode ref-only · ปรุ/die-cut/มุมตัด ·
blind-emboss seal (พื้นหลังเท่านั้น) — **แบน**: torn edge (P-LOG-086), ลายมือ, walnut,
หินอ่อน, กิ่งมะกอก, โพลารอยด์รูปจริง

## §B Spec ต่อหน้า

### B1 · HOME — "โต๊ะหน่วยเลือกตั้งยามเช้า"
**วิเคราะห์ภาพจริง:** พื้นหลัง+กองกระดาษ+โน้ต+เชืออกทำงานแล้ว แต่ (1) บัตรคิวสถานะ
"ปิดหีบแล้ว" โล่งมาก (2) คอลัมน์ซ้ายใต้ hero ว่างใหญ่ (3) แถว issue eyebrow บน =
editorial tic (4) CTA rail ขวาอ่านแยกขาดจาก hero (5) ghost stamp จนแทบมองไม่เห็น
**Composition ใหม่ (v2-R1):**
- Dispenser dock บนสุด → เทปพิมพ์ 4 ท่อน: [T1 หัวงาน: ชื่อสโมสร+โครงการ+วันเวลา
  เปิดหีบ] → [T2 บัตรคิว countdown: split-flap + label คิวเข้าคูหา] → [T3 register
  turnout: 3 บรรทัด + progress หมึก] → [T4 ท้ายเทป: barcode ref + ปลายหยัก]
- Scatter ฝั่งขวา (ทับขอบเทป): โน้ตมะนิลา CTA คำอธิบายสั้น + **ป้าย tag CTA หลัก
  ห้อยเชือกจากหมุดโน้ต** (ยกของ R2.5/R4 มาทั้งชุด) · โปสเตอร์แปะเทปโฮโล ·
  ต้นขั้ว "ดูผู้สมัคร" (CTA รอง = ต้นขั้วบัตรจริง ฉีกได้) · ซีล foil เล็ก
- สถานะปิดหีบ: ท่อน T2 เปลี่ยนเป็น **ตราปั๊มแดงเฉียงคาดเทป + บรรทัดพิมพ์
  "ปิดรับบัตรคิว · เวลาปิด {time}"** + LED เครื่องเป็นแดงจาง — แก้ "โล่ง" ด้วยเนื้อจริง
  ไม่ใช่ตกแต่งเปล่า; ทุกสถานะ CTA 6 แบบ ห้าม layout shift (กติกา R2 เดิม)
- Ghost stamp textPath: opacity .075→.12 + ขยับมาทับมุมเทปท่อน T1 (ให้เห็นจริง)
**Motion:** ท่อน T2-T4 print-reveal ตอน scroll (translateY 12px→0 + คลิปโผล่จากปรุ,
เฉพาะครั้งแรก, base-visible) · flap roll เดิม · เชือกแกว่ง ±1.5deg ตอน hover tag
**Mobile:** เครื่อง+เทปเต็มกว้าง; โน้ต/โปสเตอร์แทรกระหว่างท่อน T3/T4; tag CTA เต็มกว้าง
ใต้ T3 (เชือกสั้นลงแต่คงอยู่)
**Verify:** ทุก CTA state × 4 ธีม × 2 viewport + LED ผูก systemMode ถูก + scroll-reveal
ปิด JS แล้วเห็นครบ + Playwright shots

### B2 · VOTE MULTI — "บัตรคือท่อนเทปที่กว้างที่สุด"
**วิเคราะห์ภาพจริง:** โครงบัตร+แถว+tray ดีแล้ว แต่หัวหน้าเพจเป็น editorial (H1+deck ลอย),
แถบผู้มีสิทธิ์เป็น text แถวเดียวจืด, แถวพรรคแบนเท่ากันหมด, ปุ่มรายละเอียด generic,
เลขบัตร spacing ชิด
**Composition ใหม่ (v2-R3):**
- Dispenser → เทปกว้างพิเศษ (56vw max 640px — หน้าเดียวที่เทปกว้างกว่าปกติ เพราะ
  บัตรคือพระเอก): [T1 หัวบัตร: "บัตรลงคะแนน · BALLOT PAPER" + เลขบัตร
  `No. {SAMO} {n} · {seq}` เว้นวรรคถูก + watermark band accent 4% เต็มกว้าง] →
  [T2 คำชี้แจง 2 บรรทัด (ย้าย deck เดิมเข้าเทป)] → [T3 แถวพรรค] → [T4 งดออกเสียง] →
  [ปลายหยัก]
- แถวพรรค polish: mark-box ใหญ่ขึ้น 26px + กรอบหมึกหนา 2px; เลขพรรคเป็น
  **ตราปั๊มวงกลมหมึก accent** (ไม่ใช่เลขลอย); เมื่อเลือก = ✓ ปั๊มกด (เดิม) + **ทั้งแถว
  ได้พื้น accent 5% + ตราปั๊ม "เลือกแล้ว" จิ๋วมุมขวา**; ปุ่มรายละเอียด = ต้นขั้วจิ๋ว
  มุมตัด+ปรุซ้าย (ภาษา A3)
- Scatter ฝั่งขวา (เทปกว้าง scatter น้อย): บัตรผู้มีสิทธิ์ (voter register เดิม) กลายเป็น
  **บัตรคล้องคอวางเอียง** (ชื่อ+รหัส+รูปตัวอักษรย่อ) + แท่นหมึก+ตรายางวางรอ
  (บอกใบ้ single-flow) + ต้นขั้วกติกา 1 ใบ
- Tray ยืนยันล่าง: คงโครง แต่ผิวเป็น **ต้นขั้วรอฉีก**: ขอบบนปรุ + มุมตัด + เมื่อเลือกแล้ว
  ปุ่มยืนยันได้แถบ foil รอบ (เดิม) + ข้อความ "ฉีกต้นขั้วเพื่อยืนยัน" mono จิ๋ว
**Mobile:** เทปเต็มกว้าง; บัตรคล้องคอย้ายไปเหนือเทปเป็นแถบแคบ; tray สูงเดิม
(กติกา padding-bottom ≥ tray เดิมบังคับ)
**Verify:** ชุด R3 เดิมทั้งหมด (semantic/no-disapprove/tray/390/shared modal) + ใหม่:
ตราปั๊มเลขพรรคไม่แตะ semantic + watermark ไม่ลด contrast ชื่อพรรค (คำนวณ)

### B3 · VOTE SINGLE — "โต๊ะประทับตรา" (ช่องว่าง concept↔จอ ใหญ่สุด — ยกเครื่องโซนตัดสิน)
**วิเคราะห์ภาพจริง:** ส่วนนำเสนอพรรคครบดี แต่ (1) โซนตัดสินใจ = 3 แถว checkbox ธรรมดา
ทั้งที่ concept ระบุ "ตราปั๊ม 3 อัน" — จุดอ่อนอันดับหนึ่งของทั้งตระกูล (2) section
เกี่ยวกับพรรค/นโยบาย/ทีม เป็น editorial ล้วน ไม่มีความกระดาษ (3) หน้ายาวมากกว่าจะถึง
โซนตัดสิน ไม่มีทางลัด
**Composition ใหม่ (v2-R3):**
- เทป offset ซ้าย พิมพ์: [T1 หัว: พรรคเดียว·SINGLE BALLOT + ชื่อพรรค+ตราเลข 1] →
  [T2 เกี่ยวกับพรรค (ย่อบนเทป)] → [T3 นโยบาย = **คูปองรอยปรุ** ใบละข้อ ฉีกอ่านได้
  (hover = ใบยกเผยเงา)] → [T4 ทีม: แถบรูปแนวนอน scroll บนเทป (photo strip จาก
  เครื่องพิมพ์รูป) แทน grid 4 คอลัมน์ยาวเหยียด] → [T5 = โซนตัดสิน]
- **T5 "โต๊ะประทับตรา" (หัวใจใหม่):** บัตรตัดสินวางกลางเทป มีช่องประทับว่าง 1 ช่อง
  ("ประทับตราของคุณที่นี่" mono จาง) — ข้างเทปฝั่งขวา scatter **ตรายางจริง 3 ด้าม**
  (ด้ามไม้+หัวยาง เขียว/แดง/ส้ม semantic + ป้ายคำ รับรอง/ไม่รับรอง/งดออกเสียง)
  + แท่นหมึก 3 สี; คลิกด้าม = ด้ามยกลอย→**ประทับลงช่อง** (ตราหมุนเฉียง + หมึกซึม
  scale .9→1 + opacity) เปลี่ยนใจ = ปั๊มทับใหม่ (ตราเก่าจางเป็น ghost); แล้ว tray
  ยืนยันเดิมทำงานต่อ — **a11y: ด้าม = role=radio 3 ตัวเหมือนเดิม, keyboard เลือกได้,
  base-visible: JS-fail เห็น 3 ช่องตราแบบแถวธรรมดา (fallback = โครงเดิมปัจจุบัน)**
- ทางลัด: ต้นขั้วจิ๋ว sticky ขวาล่าง "ไปที่การตัดสินใจ ↓" โผล่หลัง scroll ผ่าน T2
  (จางบนมือถือถ้าเบียด tray)
**Verify:** semantic 3 สีคงที่ทุกธีม (probe 2 ธีม) + stamp interaction ทำงานด้วย
keyboard + fallback ไม่มี JS เห็นครบ + dispatch single/multi เดิม + shared confirm
ไม่แตะ + 390

### B4 · SUCCESS — เก็บรายละเอียด (unique อยู่แล้ว — ห้ามรื้อ)
**วิเคราะห์ภาพจริง:** แข็งแรงสุดในตระกูล; จุดเก็บ: คอลัมน์ซ้าย (headline+ปุ่ม 2) จืด,
โต๊ะรอบเครื่องว่าง
**Polish (v2-R3 เบา):**
- คอลัมน์ซ้าย: ข้อความขอบคุณอยู่บน **การ์ดโน้ตมะนิลาแปะเทป** + ปุ่มประเมิน = ป้าย tag
  ห้อยเชือก (ภาษาเดียวกับ home) + ปุ่ม results = ต้นขั้ว; ephemera: ต้นขั้วคิวที่ใช้แล้ว
  วางข้าง + ซีล foil
- เครื่องพิมพ์: เพิ่มแถบ test-print จิ๋วโผล่ข้าง slot (บรรทัด ▚▚ mono จาง) + LED เขียว
- ใบเสร็จ: คงทุกอย่าง (secrecy/บรรทัดพิมพ์/barcode) — แตะได้แค่เงา/contact shadow A4
**Verify:** printer moment ไม่เปลี่ยน timing/order + ephemeral choice path เดิม + 390

### B5 · RESULTS — "ม้วนผลนับคะแนน"
**วิเคราะห์ภาพจริง:** แถบ standings + โน้ตมะนิลาดี; อ่อนที่ headline โล่ง, ชิพ WINNER
เล็กแบน, การ์ดกราฟ generic, สีแท่ง ปี3/4 เทา-เบจขุ่น
**Composition ใหม่ (v2-R3):**
- Dispenser → เทป: [T1 หัว "ใบสรุปผลนับคะแนน" + ตราปั๊มวันประกาศ] → [T2 turnout
  register (โน้ตมะนิลาเดิมย้ายมาพิมพ์บนเทป — มือถืออ่านไล่เดียว)] → [T3 standings
  เดิม + **ผู้ชนะ: ตราปั๊มวงแหวน "ผู้ชนะ · WINNER" หมึกเขียว semantic ประทับเฉียง
  ทับแถว** แทนชิพจิ๋ว] → [T4 ปลายหยัก+สรุป]
- Demographics: กราฟอยู่บน **บัตรรายงานแปะเทปโฮโล** scatter ขวา (ทับขอบเทป);
  palette แท่ง: ไล่ accent→accentDeep→accent 55%→accent 30% (เลิกเทา-เบจขุ่น —
  ยังอยู่ในกติกา "กราฟห้ามใช้สี semantic โหวต"); recharts props เดิมห้ามแตะ
  นอก fill/สี palette ที่เราส่งเอง
