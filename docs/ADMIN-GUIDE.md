# คู่มือแอดมิน สโมสรนักศึกษา

คู่มือนี้สำหรับกรรมการสโมสรนักศึกษาที่ดูแลการเลือกตั้งผ่านหน้าแอดมินของเว็บ
ทุกอย่างในไฟล์นี้ทำได้จากเบราว์เซอร์ ไม่ต้องพิมพ์คำสั่ง และไม่ต้องเข้าเซิร์ฟเวอร์

งานหลังบ้าน เช่นเซิร์ฟเวอร์ ฐานข้อมูล และการติดตั้ง เป็นหน้าที่ของเจ้าหน้าที่ IT คณะ
คู่มือของเขาคือ [`docs/STAFF-IT-GUIDE.md`](STAFF-IT-GUIDE.md) เวลาต้องขออะไรจากเขา ดู [§6 เรื่องที่ต้องขอ IT](#6-เรื่องที่ต้องขอ-it)

ในเว็บมีคู่มือฉบับย่อให้ด้วย อยู่ที่เมนู คู่มือใช้งาน ในหน้าแอดมิน ไฟล์นี้ละเอียดกว่าและบอกข้อความที่จะขึ้นบนจอ

| ต้องการอะไร | ไปที่ |
|---|---|
| เข้าหน้าแอดมินครั้งแรก หรือลืมรหัส | [§1 เข้าระบบ](#1-เข้าระบบ) |
| เมนูแต่ละอันทำอะไร | [§2 หน้าแอดมินมีอะไรบ้าง](#2-หน้าแอดมินมีอะไรบ้าง) |
| เตรียมเลือกตั้งรอบใหม่ | [§3 ก่อนเลือกตั้ง](#3-ก่อนเลือกตั้ง) |
| วันเลือกตั้งต้องทำอะไร | [§4 วันเลือกตั้ง](#4-วันเลือกตั้ง) |
| ปิดหีบแล้ว ประกาศผลและรับรองผลยังไง | [§5 หลังปิดหีบ](#5-หลังปิดหีบ) |
| ต้องขออะไรจาก IT บ้าง | [§6 เรื่องที่ต้องขอ IT](#6-เรื่องที่ต้องขอ-it) |
| ส่งมอบให้กรรมการชุดหน้า | [§7 ส่งมอบ](#7-ส่งมอบ) |

## 1. เข้าระบบ

เปิด `https://ovs.fms.psu.ac.th/admin/login`

```
ชื่อผู้ใช้   รหัส นศ. ของตัวเอง       เช่น 6600000000
รหัสผ่าน    รหัสกลาง                 20 ตัวอักษรที่ได้จาก IT
```

ต้องมีครบสองอย่างถึงเข้าได้ คือรหัส นศ. ของคุณต้องถูกตั้งเป็นแอดมินไว้ และต้องรู้รหัสกลาง
รหัสกลางเป็นตัวเดียวกันทั้งชุดกรรมการ แต่ระบบรู้ว่าใครเป็นคนกด เพราะดูจากรหัส นศ. ที่ล็อกอิน

ช่อง รหัสผ่าน ใส่รหัสกลางล้วน ๆ ไม่ต้องเอารหัส นศ. หรืออีเมลมาต่อข้างหน้า

เข้าไม่ได้ ให้ดูข้อความที่ขึ้น:

| อาการ | ทำอะไร |
|---|---|
| ขึ้นว่า "ชื่อผู้ใช้งาน หรือ รหัสผ่าน ไม่ถูกต้อง" | ข้อความเดียวกันนี้ขึ้นได้จากสามสาเหตุ และระบบตั้งใจไม่บอกว่าเป็นข้อไหน เพื่อไม่ให้ใครใช้ฟอร์มนี้เดาว่ารหัส นศ. ไหนเป็นแอดมิน คือ (1) รหัสผ่านผิด หรือรหัสกลางถูกเปลี่ยนแล้ว (2) รหัส นศ. นี้ยังไม่ถูกตั้งเป็นแอดมิน (3) รหัส นศ. นี้ไม่มีในระบบเลย (พิมพ์ผิด หรือยังไม่ได้นำเข้า) ตรวจตัวเลขก่อน ถามคนในทีมว่าใช้รหัสกลางล่าสุดหรือยัง แล้วค่อยขอ IT ตาม [§6](#6-เรื่องที่ต้องขอ-it) บัญชีที่มีรหัสส่วนตัว (เช่น บัญชีสำรองฉุกเฉิน) ใช้รหัสกลางไม่ได้ ต้องใช้รหัสของบัญชีนั้นเอง |
| ขึ้นว่า "บัญชีเจ้าหน้าที่นี้ยังไม่ได้ตั้งรหัสของตัวเอง และใช้รหัสกลางของกรรมการเข้าไม่ได้ กรุณาติดต่อผู้ดูแลเซิร์ฟเวอร์ให้ตั้งรหัสให้ใหม่" | เกิดกับบัญชีเจ้าหน้าที่ (STAFF) ที่ไม่มีรหัสส่วนตัว ระบบไม่ยอมให้ใช้รหัสกลางแทน แจ้ง IT ให้ตั้งรหัสให้ใหม่ |
| ขึ้นว่า "ระบบยังไม่ได้ตั้งรหัสผ่านแอดมิน กรุณาติดต่อผู้ดูแลเซิร์ฟเวอร์" | ฝั่งเซิร์ฟเวอร์ยังไม่เคยตั้งรหัสกลาง และบัญชีนี้ไม่มีรหัสส่วนตัว (ระบบตอบเป็นข้อผิดพลาด 500) แจ้ง IT ให้ออกรหัสกลาง |
| ขึ้นว่า "พยายามเข้าสู่ระบบบ่อยเกินไป ลองใหม่ใน … วินาที" | ระบบกันการเดารหัส (ลองได้ 10 ครั้งใน 5 นาที) รอตามจำนวนวินาทีที่ขึ้นแล้วลองใหม่ |
| เข้าได้ แต่อยู่ ๆ ก็เด้งออก | สิทธิ์ถูกถอด หรือครบ 2 ชั่วโมง ระบบให้ล็อกอินใหม่ทุก 2 ชั่วโมงหลังเข้า ของที่แก้ค้างไว้และยังไม่กดบันทึกจะหาย |

คนในทีมเพิ่งลาออก หรือรหัสหลุด ให้ขอ IT เปลี่ยนรหัสกลาง ทุกคนจะได้รหัสใหม่พร้อมกัน

เจ้าหน้าที่คณะที่ทำหน้าที่รับรองผล ([§5](#5-หลังปิดหีบ)) ไม่ได้ใช้รหัสกลาง เขามีบัญชีเจ้าหน้าที่ (STAFF) กับรหัสส่วนตัวของเขาเอง ซึ่ง IT เป็นคนออกให้

นักศึกษาที่ล็อกอินผ่าน PSU SSO มีเวลา 1 ชั่วโมงหลังล็อกอิน แล้วต้องล็อกอินใหม่ ระบบไม่ต่ออายุให้เอง
ถ้ามีคนเปิดหน้าลงคะแนนค้างไว้นานกว่านั้นแล้วส่งบัตรไม่ได้ ให้บอกเขาล็อกอินใหม่

## 2. หน้าแอดมินมีอะไรบ้าง

เมนูอยู่ด้านซ้าย (บนมือถือกดปุ่ม เปิดเมนู มุมซ้ายบน) แบ่งเป็นสามกลุ่ม ตามลำดับที่ใช้งานจริง

| กลุ่ม | เมนู | ใช้ทำอะไร |
|---|---|---|
| วันเลือกตั้ง | ศูนย์ควบคุม | ดูสถานะและยอดผู้ใช้สิทธิ์สด เปลี่ยนโหมด ปิดหีบ ประกาศผล รับรองผล |
| เตรียมการ | ตั้งค่าทั่วไป | ชื่องาน ครั้งที่ ปีการศึกษา วันเวลาเปิดปิดหีบ โปสเตอร์ ลิงก์แบบประเมิน ชั่วโมงกิจกรรม |
| เตรียมการ | จัดการผู้สมัคร | เพิ่ม แก้ ลบพรรคและสมาชิก รูป สี นโยบาย ช่องทางติดต่อ |
| เตรียมการ | เลือกธีม | หน้าตาเว็บฝั่งนักศึกษาทั้งระบบ ดูตัวอย่างครบทุกหน้าก่อนกดใช้ |
| ระบบ | ความพร้อมและระบบ | ตรวจว่าระบบพร้อมเปิดหีบหรือยัง และอ่านคำอธิบายของแต่ละโหมด |
| ระบบ | คู่มือใช้งาน | คู่มือฉบับย่อในตัวเว็บ |

แถบด้านบนของทุกหน้าบอกชื่อหน้าที่เปิดอยู่ สถานะของหีบตอนนี้ โหมดที่ใช้อยู่ และชื่อกับบทบาทของคุณ
ถ้าแถบนี้ขึ้นป้าย เครื่องพัฒนา แปลว่าเว็บกำลังรันบนเครื่องทดสอบ ไม่ใช่ระบบจริง วันเลือกตั้งต้องเห็นป้าย ระบบจริง เท่านั้น ถ้ายังเห็น เครื่องพัฒนา ให้แจ้ง IT ก่อนเปิดให้นักศึกษาใช้

บางเครื่องมีเมนู เครื่องมือทดสอบ เพิ่มมาอีกหนึ่งเมนู เมนูนี้มีไว้ให้นักพัฒนาเพิ่มพรรคตัวอย่างและล้างบัตรบนเครื่องทดสอบเท่านั้น
บนเครื่องที่ใช้เลือกตั้งจริงต้องไม่มีเมนูนี้ ถ้าเห็น ให้แจ้ง IT ทันที

### ศูนย์ควบคุม

หน้านี้เป็นที่เดียวที่สั่งงานการเลือกตั้งที่กำลังเดินอยู่ เรียงจากบนลงล่างดังนี้

1. การ์ดสถานะ บอกสถานะของหีบตอนนี้เป็นตัวใหญ่ (เช่น ปิดหีบแล้ว) โหมดที่ใช้ เวลาเปิดหีบและปิดหีบ นับถอยหลังเมื่อใกล้ถึงเวลา
   บรรทัด ขั้นต่อไป บอกว่าควรทำอะไรต่อ ด้านขวาคือ ผู้ใช้สิทธิ์แล้ว เป็นจำนวนคนต่อผู้มีสิทธิ์ทั้งหมดพร้อมเปอร์เซ็นต์ และเวลาที่อัปเดตล่าสุด
   ถ้าขึ้นว่า "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ ตัวเลขนี้อาจไม่ใช่ล่าสุด" ให้ถือว่าตัวเลขเก่า
2. แถบผลตรวจความพร้อม สรุปว่าไม่ผ่านกี่ข้อ เตือนกี่ข้อ ผ่านกี่ข้อ ปุ่ม ดูรายละเอียด พาไปเมนู ความพร้อมและระบบ
3. กล่อง โหมดการทำงานของระบบ มีปุ่มโหมด 4 ปุ่ม ทุกครั้งที่กดจะมีกล่องให้ยืนยันก่อนเสมอ
4. กล่อง ขั้นตอนปิดการเลือกตั้ง มีสามขั้น ปิดหีบ ประกาศผล รับรองผล ดู [§5](#5-หลังปิดหีบ)
5. ส่วน ตัวเลขที่รับรองไว้ จะขึ้นหลังรับรองผลแล้วเท่านั้น ดู [§5](#5-หลังปิดหีบ)
6. กล่อง การใช้สิทธิ์แยกตามกลุ่ม แบ่งตามชั้นปี สาขา และเพศ ใช้ดูกลุ่มที่ยังมาโหวตน้อย
   แถว ไม่ระบุ คือผู้มีสิทธิ์ที่ในระบบยังไม่มีข้อมูลสาขาหรือเพศ
   ตัวเลขนี้บอกแค่ว่าใครมาใช้สิทธิ์แล้ว ไม่ได้บอกว่าเลือกใคร เพราะข้อมูลนั้นไม่มีอยู่ในระบบตั้งแต่แรก

**โหมดระบบ 4 แบบ** ปุ่มแต่ละอันเขียนชื่อโหมดเป็นภาษาอังกฤษตัวใหญ่ กับชื่อไทยใต้ลงมา โหมดที่ใช้อยู่จะมีเครื่องหมายถูกและคำว่า ใช้อยู่ตอนนี้

| ปุ่มบนจอ | ความหมาย | ใช้ตอนไหน |
|---|---|---|
| AUTO อัตโนมัติ | เปิดและปิดหีบเองตามวันเวลาใน ตั้งค่าทั่วไป | ค่าปกติ ใช้อันนี้ |
| OPEN เปิดระบบ | บังคับเปิดรับคะแนนทันที ไม่สนวันเวลา | ซ้อมระบบ หรือตั้ง AUTO ไว้แล้วระบบไม่เปิดหีบตามเวลา ไม่ใช่ปุ่มขยายเวลา (ดูกล่องด้านล่าง) |
| PAUSE ระงับ | หยุดรับคะแนนชั่วคราว นักศึกษาเห็นหน้าพักระบบ | เหตุฉุกเฉินวันเลือกตั้ง แล้วจะกลับมาเปิดต่อ |
| ENDED ปิดระบบ | ปิดหีบทันที ไม่รับคะแนนอีก | ปิดหีบก่อนเวลาด้วยมติกรรมการ หรือ AUTO ไม่ปิดหีบตามเวลา หรือกำลังใช้ OPEN อยู่แล้วหมดเวลาเลือกตั้ง |

บางปุ่มกดไม่ได้ตามสถานะ ปุ่มจะจางและขึ้นว่า "กดไม่ได้ตอนนี้ (ดูเหตุผลด้านล่าง)" เหตุผลอยู่ใต้ปุ่ม

กล่องคำเตือนเรื่อง OPEN ที่ต้องอ่านก่อนใช้:

- บนจอเขียนไว้ว่า "OPEN จะไม่เปลี่ยนเป็น ENDED เอง แม้เลยเวลาปิดหีบแล้ว เมื่อหมดเวลาเลือกตั้ง ต้องกลับมากด ENDED ด้วยตัวเอง"
- กล่องยืนยันตอนกด (หัวข้อ เปลี่ยนเป็น OPEN (เปิดระบบ)?) บอกว่า "หีบจะเปิดทันที ไม่สนวันเวลาที่ตั้งไว้ นักศึกษาที่ยังไม่ได้ลงคะแนนจะลงคะแนนได้ และหีบจะเปิดอยู่จนกว่าจะเปลี่ยนเป็น ENDED แม้เลยเวลาปิดหีบแล้ว" ถ้ากดจาก PAUSE หรือ ENDED ข้อความจะขึ้นต้นว่า "หีบจะเปิดอีกครั้งทันที"
- ระหว่างอยู่ในโหมด OPEN ประกาศผลไม่ได้ เพราะหีบยังรับคะแนนอยู่ ต้องกด ENDED ก่อน
- การ์ดสถานะจะบอกว่าโหมด OPEN ไม่ผูกกับเวลาปิดหีบ ถ้าเห็นข้อความนี้หลังเลยเวลาปิดหีบ แปลว่ายังมีคนลงคะแนนได้อยู่
- ซ้อมเสร็จแล้วห้ามทิ้งไว้ที่ OPEN ให้เปลี่ยนกลับเป็น AUTO ทุกครั้ง

**วันเวลาใน ตั้งค่าทั่วไป คือตัวคุมหีบ** ในโหมด AUTO ระบบดูช่อง เปิดหีบ กับ ปิดหีบ ตลอดเวลา แก้วันเวลาระหว่างเลือกตั้งได้ แต่ผลเกิดทันทีที่กด บันทึก:

- เลื่อน ปิดหีบ ให้เร็วขึ้นจนเลยเวลาปัจจุบัน หีบปิดทันที
- เลื่อน ปิดหีบ ออกไปหลังจากหีบปิดไปแล้ว หีบเปิดอีกครั้ง
- ช่อง เปิดตัวผู้สมัคร ไม่เกี่ยวกับหีบ แค่บอกว่าหน้ารายชื่อพรรคเริ่มแสดงเมื่อไหร่
- ถ้าต้องการขยายเวลาลงคะแนน ให้อยู่ที่ AUTO แล้วแก้ช่อง ปิดหีบ อย่าใช้ OPEN เพราะหีบจะไม่ปิดเองอีกเลย

ถ้าระบบไม่ยอมบันทึกวันเวลา จะขึ้นข้อความอย่างใดอย่างหนึ่งนี้:

| ข้อความ | แปลว่า |
|---|---|
| "เวลาปิดหีบต้องอยู่หลังเวลาเปิดหีบ" | กรอกสลับกัน แก้ให้ปิดหลังเปิด |
| "อ่านวันเวลาเปิดหีบหรือปิดหีบไม่ออก, เลือกวันเวลาใหม่จากช่องในฟอร์ม" | เลือกวันเวลาใหม่จากช่องเลือกวัน อย่าพิมพ์เอง |
| "ผลคะแนนกำลังแสดงอยู่, ซ่อนผลก่อน แล้วจึงแก้วันเวลาให้หีบเปิดอีกครั้งได้" | ประกาศผลไปแล้ว ถ้าจะแก้ให้หีบเปิดอีกต้องกด ซ่อนผล ก่อน ([§5](#5-หลังปิดหีบ)) |
| "ผลถูกรับรองแล้ว แก้วันเวลาเลือกตั้งไม่ได้" | รับรองผลแล้ว ปิดถาวรสำหรับการเลือกตั้งครั้งนี้ |

ช่องอื่นในเมนู ตั้งค่าทั่วไป (ชื่องาน ปี ลิงก์ ฯลฯ) บันทึกได้ตลอด ไม่ทำให้หีบเปิดหรือปิด

### ตั้งค่าทั่วไป

ด้านบนมีกล่อง เตรียมการเลือกตั้ง ตามด้วยชื่อรอบ เช่น SAMO 50 พร้อมตัวนับ เช่น 3 / 5 พร้อม บอกว่าเตรียมครบกี่หัวข้อแล้ว
กดแต่ละแถวเพื่อเปิดช่องกรอกของแถวนั้น แถวที่มีให้ตั้งคือ

- ครั้งที่และปีการศึกษา
- วันเวลาเลือกตั้ง (เปิดตัวผู้สมัคร เปิดหีบ ปิดหีบ) เวลาที่กรอกเป็นเวลาไทยเสมอ
- โปสเตอร์ ถ้ายังไม่อัปโหลด หน้าเว็บใช้โปสเตอร์เริ่มต้นของระบบ
- ลิงก์แบบประเมิน
- ชั่วโมงกิจกรรม

ถ้าค่าที่ตั้งไว้ยังเป็นของการเลือกตั้งที่จบไปแล้ว จะมีแถบเตือนด้านบนสุด พร้อมปุ่มที่เปิดแถววันเวลาให้แก้ทันที
ส่วน ข้อมูลองค์กร (ชื่อโครงการ ชื่อองค์กร ท้ายเว็บ) พับอยู่ด้านล่าง แทบไม่ต้องแก้

พอแก้ช่องไหน จะมีแถบด้านล่างขึ้นมาบอกว่า "แก้ไข N ช่อง ยังไม่ได้บันทึก" ต้องกด บันทึก ค่าจึงมีผลกับหน้าเว็บ
ถ้าแก้ค้างไว้แล้วกดเปลี่ยนเมนู จะมีกล่องถามก่อนว่าจะออกโดยไม่บันทึกหรือกลับไปบันทึก

### ความพร้อมและระบบ

หน้านี้ตรวจให้เองทุกครั้งที่เปิด เรียงจากบนลงล่างดังนี้

1. ป้ายสถานะการเข้าสู่ระบบจำลอง (Mock Login) ดูอย่างเดียว ถ้าขึ้นว่ายังเปิดอยู่ ให้แจ้ง IT
2. การ์ด ตรวจความพร้อมระบบ ใต้หัวมีเวลาที่ตรวจล่าสุด และปุ่ม ตรวจซ้ำ ที่กดได้หลังแก้ปัญหา ข้างล่างมีส่วน กำหนดการปัจจุบัน
   สรุปเวลาเปิดตัวผู้สมัคร เปิดหีบ ปิดหีบ ว่าตั้งไว้แล้วหรือยังเป็นค่าเริ่มต้น
3. กล่อง แต่ละโหมดใช้ตอนไหน อธิบายโหมดทั้งสี่ และสิ่งที่นักศึกษาจะเห็นในแต่ละโหมด หน้านี้ไว้อ่านประกอบ การเปลี่ยนโหมดทำที่ศูนย์ควบคุม
4. กล่อง ขึ้นปีการศึกษาใหม่ อธิบายว่าการล้างคะแนน บัตร และรายชื่อพรรคของปีเก่าเป็นงานของ IT ไม่มีปุ่มในหน้านี้โดยตั้งใจ
   เพราะบัญชีฐานข้อมูลที่เว็บใช้ถูกตั้งให้เพิ่มบัตรได้แต่ลบบัตรไม่ได้ เป็นหลักประกันว่าผลที่ลงไปแล้วแก้ไม่ได้ แม้แต่จากหน้าแอดมิน

## 3. ก่อนเลือกตั้ง

เริ่มก่อนวันจริงอย่างน้อย 1 ถึง 2 สัปดาห์

1. แจ้ง IT ล่วงหน้าว่าจะจัดเลือกตั้งเมื่อไหร่ เขาต้องล้างข้อมูลปีเก่า นำเข้ารายชื่อผู้มีสิทธิ์
   ทำพิธีสร้างกุญแจบัตร และสร้างบัญชีเจ้าหน้าที่สำหรับรับรองผล ([§6](#6-เรื่องที่ต้องขอ-it))
2. เมนู ตั้งค่าทั่วไป กรอกให้ครบทุกแถว โดยเฉพาะวันเวลา 3 ช่อง (เปิดตัวผู้สมัคร เปิดหีบ ปิดหีบ) เวลาที่กรอกเป็นเวลาไทยเสมอ
   - ลิงก์ Google Form ในแถว ลิงก์แบบประเมิน บนจอเขียนว่าถ้าเว้นว่าง ปีนี้ไม่มีแบบประเมิน ไม่มีปุ่ม และไม่ล็อกหน้าผลคะแนน
     ถ้าใส่ลิงก์ไว้ ระหว่างที่หีบยังเปิด นักศึกษาที่ลงคะแนนแล้วต้องทำแบบประเมินก่อนถึงจะเข้าหน้าผลคะแนนได้
     ปีไหนไม่มีแบบประเมินก็เว้นว่างได้เลย การตรวจความพร้อมจะแค่ขึ้นเตือน
   - ช่องชั่วโมงกิจกรรม ใส่เลขเมื่อคณะยืนยันแล้วเท่านั้น ไม่แน่ใจให้เว้นว่าง
3. เมนู จัดการผู้สมัคร กรอกพรรค สมาชิก รูป นโยบาย ให้ครบ และให้จบก่อนซ้อมระบบ (ดูข้อควรระวัง ก ด้านล่าง)
   ตัวเลือก งดออกเสียง และ ไม่รับรอง ระบบสร้างและลบให้เองตามจำนวนพรรค
   ถ้ามีพรรคเดียว ระบบจะสลับเป็นบัตร รับรอง / ไม่รับรอง / งดออกเสียง ให้เอง
4. เมนู เลือกธีม เลือกหน้าตาเว็บของปีนั้น ดูตัวอย่างก่อนได้ทุกหน้า แล้วกด ใช้ธีมนี้
5. ที่ศูนย์ควบคุม ตั้งโหมดเป็น AUTO ขั้น ปิดหีบ ต้องขึ้นว่า "หีบยังเปิดรับคะแนนอยู่" และขั้น ประกาศผล ต้องขึ้นว่า "ประกาศได้หลังปิดหีบ"
   ไม่ต้องกลัวผลรั่ว ระบบไม่ยอมประกาศผลก่อนหีบปิดอยู่แล้ว
6. ไปที่เมนู ความพร้อมและระบบ ดูการ์ด ตรวจความพร้อมระบบ เป็นด่านสุดท้าย ระบบตรวจให้เอง 18 ข้อ (รวมอีเมลติดต่อเรื่องข้อมูลส่วนบุคคล ตั้งที่เมนูตั้งค่าทั่วไป แถวสุดท้าย แสดงบนหน้า /privacy ซึ่งต้องให้เจ้าหน้าที่คุ้มครองข้อมูลของคณะตรวจก่อนใช้จริง)
   โดยไม่แก้ข้อมูลอะไร หลังแก้ปัญหาแล้วกด ตรวจซ้ำ
   - ด้านบนมีป้ายสรุป ไม่ผ่าน / เตือน / ผ่าน พร้อมจำนวน ข้อที่ไม่ผ่านขึ้นก่อนเสมอ กดป้ายเพื่อดูเฉพาะระดับนั้น กดซ้ำเพื่อกลับมาดูทั้งหมด
   - ต้องไม่มีข้อ ไม่ผ่าน (สีแดง) ส่วนข้อ เตือน (สีเหลือง) ให้อ่านแล้วแน่ใจว่ารู้และตั้งใจ
   - ถ้าข้อ "ตัวเลือกกรณีพรรคเดียว" ไม่ผ่าน จะมีปุ่ม สร้างตัวเลือกที่ขาดให้อัตโนมัติ อยู่ใต้ข้อนั้น กดได้เลย
   - ข้อต่อไปนี้กรรมการแก้เองไม่ได้ ถ้าแดงหรือเหลืองให้ส่งภาพหน้าจอให้ IT: "การเข้าสู่ระบบจำลอง (ใช้ทดสอบ)",
     "โฟลเดอร์เก็บรูปที่อัปโหลด", "สำรองข้อมูลอัตโนมัติ (backup)", "เครื่องมือทดสอบของแอดมิน",
     "รายชื่อผู้มีสิทธิ์เลือกตั้ง" และ "ความสอดคล้องของคะแนน"
   - ข้อ "โฟลเดอร์เก็บรูปที่อัปโหลด" ขึ้นเหลืองได้ตั้งแต่ติดตั้งครั้งแรก ให้ถาม IT ครั้งเดียวว่าระบบนี้รันด้วย Docker หรือไม่
     ถ้าใช่ ขึ้นเหลืองเป็นปกติถาวร ไม่ต้องแก้อะไร เพราะหน้านี้ดูแค่ว่าที่เก็บรูปอยู่นอกโฟลเดอร์ตัวโปรแกรมหรือไม่ ส่วน Docker เก็บรูปไว้บนเครื่องโฮสต์ให้อยู่แล้ว
     (ข้อความเตือนในข้อนั้นจะแนะนำให้ย้ายที่เก็บรูป ซึ่งไม่ต้องทำบน Docker) ถ้าไม่ใช่ Docker ให้แจ้ง IT ไว้ ไม่ใช่เรื่องฉุกเฉิน
     แต่ถ้าแดง แปลว่าอัปโหลดรูปไม่ได้เลย ต้องแจ้งทันที

**ซ้อมระบบ** ทำได้ด้วยโหมด OPEN แล้วกลับมาที่ AUTO ซ้อมเสร็จต้องให้ IT ล้างคะแนนทดสอบก่อนวันจริงเสมอ
([STAFF-IT-GUIDE §5](STAFF-IT-GUIDE.md#annual-reset)) ไม่งั้นคะแนนซ้อมจะปนกับของจริง ระหว่างซ้อมมีสามเรื่องที่ต้องระวัง

ก. บัตรใบแรกล็อกโครงสร้างบัตร พอมีบัตรในระบบแม้แต่ใบเดียว (รวมบัตรซ้อม) จะเพิ่มพรรค ลบพรรค หรือเปลี่ยนหมายเลขพรรคไม่ได้อีก
ระบบจะขึ้นว่า "มีบัตรลงคะแนนในระบบแล้ว … ใบ จึงเพิ่มพรรคใหม่ไม่ได้" (หรือ "จึงลบพรรคไม่ได้" / "จึงเปลี่ยนหมายเลขพรรคไม่ได้")
แก้สโลแกน รูป นโยบาย ยังทำได้ตามปกติ จึงควรใส่พรรคให้ครบก่อนซ้อม ถ้าซ้อมไปแล้วต้องให้ IT ล้างคะแนนซ้อมก่อนถึงจะแก้ได้

ข. ห้ามกด รับรองผล ตอนซ้อม รับรองแล้วเปลี่ยนโหมดได้แค่ ENDED อย่างเดียว แก้วันเวลาไม่ได้ และย้อนกลับเองไม่ได้ ต้องให้ IT ปลดให้ ([STAFF-IT-GUIDE §5](STAFF-IT-GUIDE.md#annual-reset))

ค. ถ้าซ้อมจนถึงประกาศผล ต้องกด ซ่อนผล ก่อนสลับโหมดกลับ ไม่งั้นปุ่มโหมดอื่นจะกดไม่ได้
และขึ้นว่า "ผลคะแนนกำลังแสดงอยู่, ปิดการแสดงผลก่อน แล้วจึงเปิดหีบหรือพักระบบได้"

## 4. วันเลือกตั้ง

ปกติไม่ต้องทำอะไรเลย ระบบเปิดและปิดตามเวลาที่ตั้งไว้

- ดูยอดผู้ใช้สิทธิ์สดที่เมนู ศูนย์ควบคุม
- ระบบไม่แสดงว่าใครเลือกพรรคไหน ข้อมูลนั้นไม่มีอยู่ในระบบตั้งแต่แรก ต่อให้เป็นแอดมินก็ดูไม่ได้
- อยากขยายเวลา ให้แก้ช่อง ปิดหีบ ในเมนู ตั้งค่าทั่วไป ตามที่อธิบายใน [§2](#2-หน้าแอดมินมีอะไรบ้าง) อย่าใช้ OPEN
- ในโหมด AUTO พอถึงเวลาปิดหีบ บัตรที่ยังรอคิวบันทึกอยู่ตอนนั้นจะถูกปฏิเสธ นักศึกษาที่กดส่งช้าไปเสี้ยววินาทีจะเห็นข้อความว่าปิดหีบแล้ว
  เป็นเรื่องปกติและตั้งใจไว้ ไม่ใช่ระบบเสีย ถ้ากรรมการต้องการให้ลงคะแนนต่อ ต้องขยายเวลาปิดหีบก่อนถึงเวลาเดิม
- นักศึกษาต้องล็อกอินใหม่ถ้าล็อกอินไว้เกิน 1 ชั่วโมง ถ้ามีคนแจ้งว่าส่งบัตรไม่ได้ ให้ถามก่อนว่าเปิดหน้าค้างไว้นานแค่ไหน

ถ้ามีปัญหา เช่นเว็บช้ามาก มีคนแจ้งว่าโหวตไม่ได้ หรือพบข้อผิดพลาดในข้อมูลพรรค:

1. สลับโหมดเป็น PAUSE ที่ศูนย์ควบคุมทันที กล่องยืนยันจะบอกว่า
   "หยุดรับคะแนนชั่วคราว นักศึกษาจะเห็นหน้าพักระบบ และลงคะแนนไม่ได้จนกว่าจะเปลี่ยนโหมดกลับ"
   บัตรที่ลงไปแล้วปลอดภัย ไม่หาย ไม่ซ้ำ ระหว่างนี้หน้าเว็บฝั่งนักศึกษาขึ้นข้อความพักระบบ (เช่น "หยุดรับคะแนนชั่วคราว" หรือ "พักระบบชั่วคราว" แล้วแต่ธีม)
   และการ์ดสถานะขึ้นว่า "หยุดรับคะแนนชั่วคราว"
2. แจ้ง IT พร้อมบอกว่าเกิดตอนไหน อาการอะไร
3. แก้เสร็จแล้วสลับกลับ AUTO ถ้ากลับมาตอนเลยเวลาปิดหีบไปแล้ว กล่องยืนยันจะบอกว่า "เลยเวลาปิดหีบแล้ว หีบจะยังปิดอยู่ตามกำหนดการ"
   ถ้าต้องการเวลาเพิ่มเพื่อชดเชยช่วงที่พัก ให้แก้ช่อง ปิดหีบ ก่อนแล้วค่อยกลับเป็น AUTO

อย่าลืมสลับกลับ ถ้าค้างที่ PAUSE นักศึกษาจะโหวตไม่ได้ทั้งวัน และ PAUSE ไม่ใช่การปิดหีบ ระหว่าง PAUSE ประกาศผลไม่ได้ จะจบการเลือกตั้งต้องใช้ ENDED

## 5. หลังปิดหีบ

ทุกอย่างอยู่ในกล่อง ขั้นตอนปิดการเลือกตั้ง ของเมนู ศูนย์ควบคุม
บนจอเขียนว่า "ทำตามลำดับ ปุ่มของขั้นถัดไปจะกดได้เมื่อขั้นก่อนหน้าเสร็จแล้ว" มีสามขั้น

**ขั้นที่ 1 ปิดหีบ**

- ในโหมด AUTO หีบปิดเองเมื่อถึงเวลาปิดหีบ ไม่ต้องกดอะไร ขั้นนี้จะขึ้นว่า "ปิดตามเวลา …" แล้วเป็นเสร็จ
- ถ้าใช้ OPEN อยู่ หรือกรรมการมีมติปิดก่อนเวลา ให้กดปุ่ม ปิดหีบตอนนี้ (ENDED)
  กล่องยืนยัน เปลี่ยนเป็น ENDED (ปิดระบบ)? บอกว่า "ปิดหีบทันที ไม่รับคะแนนอีก ผลคะแนนยังไม่แสดงจนกว่าจะเปิดการแสดงผล"
  เสร็จแล้วขั้นนี้ขึ้นว่า "ปิดด้วยโหมด ENDED"
- ปิดหีบแล้วยังไม่มีใครเห็นคะแนนรายพรรค รวมถึงแอดมินเอง จนกว่าจะประกาศผล

**ขั้นที่ 2 ประกาศผล**

- กดปุ่ม ประกาศผล ได้หลังปิดหีบเท่านั้น ก่อนหน้านั้นปุ่มจาง สถานะข้างขั้นนี้ขึ้นว่า "ประกาศได้หลังปิดหีบ" และเอาเมาส์ชี้ที่ปุ่มจะเห็น "ประกาศได้หลังปิดหีบแล้วเท่านั้น"
  กล่องยืนยัน ประกาศผลคะแนน? บอกว่า "ทุกคนจะเห็นคะแนนรายพรรคและสถิติผู้ใช้สิทธิ์ที่หน้าผลคะแนนทันที เมื่อประกาศแล้ว จะเปิดหีบอีกไม่ได้จนกว่าจะซ่อนผลก่อน"
  สำเร็จแล้วขึ้นว่า "เปิดแสดงผลคะแนนแล้ว ทุกคนดูผลได้ที่หน้าผลคะแนน"
- หน้าผลคะแนนที่นักศึกษาเปิดค้างไว้จะเปลี่ยนเป็นผลเอง ไม่ต้องบอกให้ใครกดรีเฟรช หน้านั้นถามเซิร์ฟเวอร์เป็นรอบ ๆ ตามสถานะ
  (หีบปิดแล้วรอประกาศผลทุก 5 วินาที หีบยังเปิดอยู่ทุก 10 ถึง 15 วินาที) และเซิร์ฟเวอร์เก็บผลไว้ชั่วครู่ราว 4 วินาที
  ปกติจึงเห็นผลภายใน 10 วินาทีหลังกดประกาศ อย่างช้าราว 20 วินาที
- ถ้าระบบตอบว่า "ยังเปิดแสดงผลไม่ได้, หีบยังไม่ปิด เปลี่ยนเป็น ENDED หรือรอให้เลยเวลาปิดหีบก่อน แล้วค่อยเปิดแสดงผล"
  แปลว่าหีบยังรับคะแนนได้อยู่ (มักเป็นเพราะค้างที่ OPEN หรือ PAUSE) กลับไปทำขั้นที่ 1 ก่อน
- ระหว่างที่ผลแสดงอยู่ ใต้ปุ่มโหมดจะขึ้นว่า "ผลคะแนนกำลังแสดงอยู่ จึงเปิดหีบหรือพักระบบไม่ได้ ถ้าต้องเปิดหีบอีกครั้ง ให้ซ่อนผลในขั้นตอนปิดการเลือกตั้งด้านล่างก่อน"
- ประกาศผิดจังหวะ หรือต้องเปิดหีบอีกครั้ง ในขั้นนี้มีปุ่ม ซ่อนผล (มีเฉพาะตอนผลแสดงอยู่และยังไม่ได้รับรองผล)
  กล่องยืนยัน ซ่อนผลคะแนน? บอกว่า "เมื่อซ่อนผลคะแนน คะแนนของแต่ละพรรคจะถูกปิดจากทุกคนรวมถึงแอดมินเอง ความคืบหน้าการใช้สิทธิ์ในศูนย์ควบคุมยังดูได้ตามปกติ"
  หลังรับรองผลแล้วปุ่มนี้หายไป และระบบไม่ยอมซ่อน ("ผลถูกรับรองแล้ว ซ่อนผลไม่ได้, ผลที่รับรองแล้วต้องแสดงต่อสาธารณะ")

**ขั้นที่ 3 รับรองผลอย่างเป็นทางการ** (มีป้าย ไม่บังคับ)

- ปุ่ม รับรองผล กรรมการสโมสรกดไม่ได้ ต้องเป็นเจ้าหน้าที่คณะเข้าด้วยบัญชีเจ้าหน้าที่ของเขาเองเท่านั้น
  เพราะการรับรองผลคือการเซ็นชื่อรับรองการเลือกตั้งของสโมสร ให้คนนอกเป็นคนเซ็นจึงตรวจสอบได้มากกว่า
  ถ้ากรรมการเผลอกด จะขึ้น "ดำเนินการไม่สำเร็จ (403)" กับข้อความ
  "รับรองผลได้เฉพาะบัญชีเจ้าหน้าที่คณะเท่านั้น, ให้เจ้าหน้าที่เข้าสู่ระบบด้วยบัญชีของตนเองแล้วกดรับรอง" ไม่มีอะไรเสียหาย
- กดได้หลังประกาศผลแล้วเท่านั้น ก่อนนั้นปุ่มจาง สถานะข้างขั้นนี้ขึ้นว่า "รับรองได้หลังประกาศผล" และเอาเมาส์ชี้ที่ปุ่มจะเห็น "ต้องประกาศผลก่อน"
  ถ้าระบบตอบว่า "ทำได้เฉพาะหลังปิดหีบและเผยแพร่ผลแล้วเท่านั้น" ให้กลับไปทำขั้นที่ 1 และ 2 ให้เสร็จ
- ก่อนบอกเจ้าหน้าที่ว่าพร้อม แนะนำให้ขอ IT ตรวจคะแนน (reconcile) ก่อน ตามขั้นตอนใน
  [STAFF-IT-GUIDE §4.3](STAFF-IT-GUIDE.md#43-ตรวจคะแนนและรับรองผล) บนจอไม่มีขั้นนี้ เป็นเรื่องที่ตกลงกับ IT เอง
- กล่องยืนยัน รับรองผลอย่างเป็นทางการ? ของเจ้าหน้าที่ลงท้ายว่า "กดแล้วย้อนกลับไม่ได้"
  ตอนกด ระบบตรวจก่อนว่าโซ่ของบัตรทุกใบยังต่อกันครบ และจำนวนบัตร คะแนนรวม กับจำนวนผู้ลงคะแนนตรงกันทั้งสามค่า
  ถ้าไม่ตรง ระบบจะไม่รับรองให้และบอกเหตุ ไม่ต้องลองกดซ้ำ ให้ถ่ายภาพหน้าจอส่ง IT
  ถ้าผ่าน ระบบบันทึกชื่อคนที่กดกับเวลา ขึ้นเป็นแถบรับรองบนหน้าผลคะแนน และบันทึกตัวเลขที่รับรองไว้ การรับรองไม่ลบข้อมูลอะไร
- หลังรับรองผล ส่วน ตัวเลขที่รับรองไว้ จะขึ้นในศูนย์ควบคุม มีผู้รับรอง เวลา คะแนนของแต่ละตัวเลือก จำนวนบัตรในหีบ และปลายโซ่บัตร
  **เจ้าหน้าที่ต้องเก็บสำเนาตัวเลขชุดนี้ไว้นอกระบบ** กดปุ่ม คัดลอกเป็นข้อความ หรือ ดาวน์โหลดเป็นไฟล์ข้อความ แล้วพิมพ์ลงกระดาษหรือเก็บไว้อีกเครื่องหนึ่ง
  เหตุผลคือถ้ามีใครแก้ตัวเลขในฐานข้อมูลภายหลัง จะตรวจเทียบกับสำเนานี้ได้
  ผลที่รับรองไปก่อนที่ระบบจะเริ่มบันทึกตัวเลขชุดนี้ จะขึ้นข้อความว่าไม่มีตัวเลขให้เก็บสำเนา
- หลังรับรองผล ระบบจะล็อก เปลี่ยนโหมดได้แค่ ENDED (ปุ่มอื่นจาง ใต้ปุ่มโหมดขึ้นว่า "ผลถูกรับรองแล้ว การเลือกตั้งครั้งนี้ปิดอย่างเป็นทางการ เปลี่ยนโหมดอื่นไม่ได้" และเอาเมาส์ชี้ที่ปุ่มจะเห็น "ผลถูกรับรองแล้ว เปลี่ยนโหมดไม่ได้, การเลือกตั้งครั้งนี้ปิดอย่างเป็นทางการ")
  เปิดหีบใหม่ไม่ได้ รับคะแนนเพิ่มไม่ได้ แก้วันเวลาไม่ได้ เพิ่ม ลบ หรือเปลี่ยนหมายเลขพรรคไม่ได้ และซ่อนผลไม่ได้ ตรวจให้แน่ก่อนบอกเจ้าหน้าที่ว่าพร้อม

หลังรับรองแล้ว IT จะรันคำสั่งตรวจอีกรอบเทียบกับตัวเลขที่รับรองไว้ ถ้ามีค่าไม่ตรง คำสั่งจะบอกว่าค่าไหนต่างไป
ให้เจ้าหน้าที่เทียบกับสำเนาที่เก็บไว้ด้วยตาอีกครั้งเมื่อมีข้อสงสัย

สุดท้าย ส่งมอบให้กรรมการชุดหน้า ([§7](#7-ส่งมอบ))

อยากได้ผลเป็นเอกสารไปแนบรายงาน เปิดหน้าผลคะแนนแล้วสั่งพิมพ์ (Ctrl+P)
ถ้ารับรองผลแล้ว จะได้หน้าที่มีแถบรับรองพร้อมชื่อผู้รับรองและวันเวลา เมนูกับปุ่มถูกซ่อนให้อัตโนมัติ
เลือก บันทึกเป็น PDF ก็ได้ไฟล์ไปใช้ได้เลย ไม่ต้องขออะไรจาก IT

ถ้ามีคนตั้งคำถามกับผลคะแนน ระบบพิสูจน์ได้ว่าบัตรทุกใบไม่ถูกแก้ไข และถ้าถึงขั้นต้องนับใหม่ก็ทำได้ต่อหน้ากรรมการ
ทั้งสองอย่างเป็นงานของ IT แจ้งเขาได้เลย ([STAFF-IT-GUIDE §4.3](STAFF-IT-GUIDE.md#43-ตรวจคะแนนและรับรองผล))

## 6. เรื่องที่ต้องขอ IT

สิ่งเหล่านี้ทำในหน้าแอดมินไม่ได้โดยตั้งใจ ต้องเข้าเซิร์ฟเวอร์ ซึ่งเป็นงานของ IT คณะ
ขั้นตอนฝั่งเขาอยู่ในหัวข้อที่ลิงก์ไว้ ไม่ต้องอ่านเอง แค่บอกเขาว่าเป็นหัวข้อไหน

| เรื่อง | บอกเขาว่า | ควรแจ้งล่วงหน้า |
|---|---|---|
| เพิ่มกรรมการเป็นแอดมิน | ขอเพิ่มสิทธิ์แอดมินให้รหัส นศ. …… ([§4.1](STAFF-IT-GUIDE.md#41-บัญชีเจ้าหน้าที่และกรรมการ)) | 2-3 วัน |
| ถอดสิทธิ์คนที่พ้นวาระ | ขอถอดสิทธิ์แอดมินของรหัส นศ. …… ([§4.1](STAFF-IT-GUIDE.md#41-บัญชีเจ้าหน้าที่และกรรมการ)) | ทันทีที่พ้นวาระ |
| ลืมรหัสกลาง หรือรหัสหลุด | ขอออกรหัสกลางใหม่ ([§4.1](STAFF-IT-GUIDE.md#41-บัญชีเจ้าหน้าที่และกรรมการ)) | ทันที |
| บัญชีเจ้าหน้าที่ (STAFF) สำหรับรับรองผล | ขอเพิ่มบัญชีเจ้าหน้าที่ STAFF สำหรับรับรองผลให้ …… ([§4.1](STAFF-IT-GUIDE.md#41-บัญชีเจ้าหน้าที่และกรรมการ)) | 1 สัปดาห์ |
| นำเข้ารายชื่อผู้มีสิทธิ์ปีนี้ | ส่งไฟล์รายชื่อให้เขา import ([§4.2](STAFF-IT-GUIDE.md#42-นำเข้ารายชื่อผู้มีสิทธิ์)) | 1 สัปดาห์ |
| ล้างข้อมูลปีเก่า ล้างคะแนนซ้อม หรือปลดการรับรองที่กดผิดตอนซ้อม | ขอล้างข้อมูลเพื่อเริ่มปีใหม่ ([§5](STAFF-IT-GUIDE.md#annual-reset)) | 1 สัปดาห์ |
| พิธีสร้างกุญแจบัตร | นัดวันกับ IT ([§3.3](STAFF-IT-GUIDE.md#33-พิธีสร้างกุญแจบัตร-ก่อนเริ่มการเลือกตั้ง)) | 1 สัปดาห์ |
| ตรวจความพร้อมขึ้นแดงหรือเหลืองในข้อที่แก้เองไม่ได้ | ส่งภาพหน้าจอข้อนั้นให้เขา | ก่อนวันจริง |
| ข้อ "สำรองข้อมูลอัตโนมัติ (backup)" ขึ้นเหลืองหรือแดง | ส่งภาพหน้าจอข้อนั้น ระบบควรสำรองเองทุก 6 ชั่วโมง ([§6.1](STAFF-IT-GUIDE.md#61-สำรองข้อมูล)) | ทันที (แดง) หรือวันทำการถัดไป (เหลือง) |
| ข้อ "โฟลเดอร์เก็บรูปที่อัปโหลด" ขึ้นแดง หรืออัปโหลดรูปไม่ได้ หรือรูปหาย | ส่งภาพหน้าจอ ([§7.2](STAFF-IT-GUIDE.md#72-อัปโหลดรูปไม่ได้บน-linux), [§7.3](STAFF-IT-GUIDE.md#73-รูปที่อัปโหลดหายหรือขึ้นเป็นช่องว่าง)) | ทันที |
| ตรวจคะแนนหลังปิดหีบ | ขอผลการตรวจ reconcile และการตรวจโซ่บัตรก่อนเจ้าหน้าที่รับรองผล ([§4.3](STAFF-IT-GUIDE.md#43-ตรวจคะแนนและรับรองผล)) | วันปิดหีบ |
| ระบบปฏิเสธการรับรองผลและบอกว่าตัวเลขไม่ตรงกัน | ส่งภาพหน้าจอข้อความ และอย่ากดซ้ำ | ทันที |
| ตรวจเทียบกับตัวเลขที่รับรองไว้หลังรับรองผล | ขอให้รัน verify-ballot-chain และบอกผล ([§4.3](STAFF-IT-GUIDE.md#43-ตรวจคะแนนและรับรองผล)) | หลังรับรอง |
| เว็บล่มหรือช้าผิดปกติ | บอกเวลาที่เกิด อาการ และภาพหน้าจอ | ทันที |

เวลาแจ้ง ให้ข้อมูลสามอย่างเสมอ คือเกิดตอนไหน กำลังทำอะไรอยู่ และข้อความบนจอ (ถ่ายรูปมา)

## 7. ส่งมอบ

จบการเลือกตั้งแล้ว ก่อนหมดวาระ:

1. ขอ IT ถอดสิทธิ์แอดมินของกรรมการชุดคุณทุกคน แล้วออกรหัสกลางใหม่ให้ชุดถัดไป
   สำคัญ: คนที่พ้นวาระยังจำรหัสเดิมได้ ต้องตัดทั้งสิทธิ์และรหัส
2. ส่งไฟล์นี้ให้กรรมการชุดใหม่ พร้อมบอกว่าใครคือผู้ติดต่อฝั่ง IT
3. ข้อมูลที่กรอกไว้ (พรรค ธีม การตั้งค่า) ยังอยู่ ชุดใหม่แก้ทับได้เลย
4. ตรวจว่าเจ้าหน้าที่เก็บสำเนา "ตัวเลขที่รับรองไว้" ของปีนี้แล้ว และบอกชุดใหม่ว่าเก็บไว้ที่ไหน
