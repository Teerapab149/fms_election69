# คู่มือแอดมิน — สโมสรนักศึกษา

สำหรับ **กรรมการสโมสรนักศึกษา** ที่ดูแลการเลือกตั้งผ่านหน้าแอดมินของเว็บ
ทุกอย่างในไฟล์นี้ทำได้จากเบราว์เซอร์ ไม่ต้องพิมพ์คำสั่ง ไม่ต้องเข้าเซิร์ฟเวอร์

> **งานหลังบ้าน (เซิร์ฟเวอร์ ฐานข้อมูล การติดตั้ง) ไม่ใช่หน้าที่ของคุณ**
> เป็นของเจ้าหน้าที่ IT คณะ คู่มือของเขาคือ `docs/STAFF-IT-GUIDE.md`
> เวลาต้องขออะไรจากเขา ดู [§6 เรื่องที่ต้องขอ IT](#6-เรื่องที่ต้องขอ-it)

## 1. เข้าระบบ

`https://<เว็บของคณะ>/fms-ovs/admin/login`

```
Username   รหัส นศ. ของตัวเอง       เช่น 6610510149
Password   รหัสกลาง                 20 ตัวอักษรที่ได้จาก IT
```

**ต้องมีครบสองอย่างถึงเข้าได้** — รหัส นศ. ของคุณต้องถูกตั้งเป็นแอดมินไว้ **และ** ต้องรู้รหัสกลาง
รหัสกลางเป็นตัวเดียวกันทั้งชุดกรรมการ แต่ระบบรู้ว่าใครเป็นคนกด เพราะดูจากรหัส นศ. ที่ล็อกอิน

> ⚠️ Password คือรหัสกลางล้วน ๆ ไม่ต้องเอารหัส นศ. หรืออีเมลมาต่อข้างหน้า

**เข้าไม่ได้?**

| อาการ | ทำอะไร |
|---|---|
| ขึ้นว่า "ไม่มีสิทธิ์เข้าถึง" | รหัส นศ. คุณยังไม่ถูกตั้งเป็นแอดมิน → ขอ IT ([§6](#6-เรื่องที่ต้องขอ-it)) |
| ขึ้นว่า "ชื่อผู้ใช้งาน หรือ รหัสผ่าน ไม่ถูกต้อง" | รหัสกลางผิด หรือรหัสถูกเปลี่ยนแล้ว → ถามคนในทีมก่อน แล้วค่อยขอ IT |
| ขึ้นว่า "พยายามเข้าสู่ระบบบ่อยเกินไป" | ระบบกันเดารหัส รอ 5 นาทีแล้วลองใหม่ |
| เข้าได้แต่พออยู่ ๆ ก็เด้งออก | สิทธิ์ถูกถอด หรือครบ 2 ชั่วโมง (ระบบให้ล็อกอินซ้ำทุก 2 ชม.) |

**คนในทีมเพิ่งลาออก / รหัสหลุด** → ขอ IT เปลี่ยนรหัสกลาง ทุกคนจะได้รหัสใหม่พร้อมกัน

## 2. หน้าแอดมินมีอะไรบ้าง

| แท็บ | ใช้ทำอะไร |
|---|---|
| **คู่มือใช้งาน** | คู่มือฉบับย่อในตัวเว็บเอง ไล่เป็นระยะ 1-4 อ่านตรงนี้ก็ได้ ไม่ต้องเปิดไฟล์ |
| **ภาพรวม** | ยอดผู้ใช้สิทธิ์แบบสด แยกตามชั้นปี/สาขา/เพศ (บอกแค่ว่ามาใช้สิทธิ์กี่คน ไม่บอกว่าเลือกใคร) |
| **ตั้งค่าทั่วไป** | ชื่องาน ปีการศึกษา เลขครั้งที่ **วันเวลาเปิด-ปิดหีบ** ลิงก์แบบประเมิน |
| **จัดการผู้สมัคร** | เพิ่ม/แก้/ลบพรรคและสมาชิก รูป สี นโยบาย |
| **เลือกธีม** | หน้าตาเว็บทั้งระบบ 6 ตระกูล ดูตัวอย่างก่อนเปลี่ยนได้ |
| **ตั้งค่าระบบ** | โหมดระบบ · สวิตช์แสดงผลคะแนน · **ปุ่มตรวจความพร้อม** · รับรองผล (เจ้าหน้าที่กดเท่านั้น) |

**โหมดระบบ 4 แบบ** (แท็บตั้งค่าระบบ):

| โหมด | ความหมาย | ใช้ตอนไหน |
|---|---|---|
| `AUTO` | เปิด-ปิดตามวันเวลาที่ตั้งไว้ | **ค่าปกติ ใช้อันนี้** |
| `MANUAL_OPEN` | บังคับเปิดโดยไม่สนเวลา | ซ้อมระบบ หรือขยายเวลากะทันหัน |
| `PAUSE` | หยุดรับโหวตชั่วคราว | **ฉุกเฉินวันเลือกตั้ง** |
| `ENDED` | ปิดอย่างเป็นทางการ | ปิดหีบก่อนเวลาด้วยมติกรรมการ |

## 3. ก่อนเลือกตั้ง

เริ่มก่อนวันจริงอย่างน้อย 1-2 สัปดาห์

1. **แจ้ง IT ล่วงหน้า** ว่าจะจัดเลือกตั้งเมื่อไหร่ — เขาต้องล้างข้อมูลปีเก่า นำเข้ารายชื่อผู้มีสิทธิ์
   และทำพิธีสร้างกุญแจบัตร ([§6](#6-เรื่องที่ต้องขอ-it))
2. **แท็บตั้งค่าทั่วไป** — ชื่องาน ปีการศึกษา เลขครั้งที่ และ **วันเวลา 3 ช่อง**
   (เปิดตัวผู้สมัคร / เปิดหีบ / ปิดหีบ) เวลาที่กรอกเป็นเวลาไทยเสมอ
3. **แท็บจัดการผู้สมัคร** — กรอกพรรค สมาชิก รูป นโยบาย ให้ครบ
   - มีพรรคเดียว ระบบจะสลับเป็นบัตร รับรอง / ไม่รับรอง / งดออกเสียง ให้เอง
4. **แท็บเลือกธีม** — เลือกหน้าตาเว็บของปีนั้น กดดูตัวอย่างก่อนได้
5. **แท็บตั้งค่าระบบ** — โหมด `AUTO` · สวิตช์แสดงผลคะแนน **ปิด**
6. **กดปุ่ม "ตรวจความพร้อมระบบ"** เป็นด่านสุดท้าย ระบบเช็คให้เอง 14 ข้อ
   **ต้องไม่มีข้อสีแดง** ข้อไหนแดงแล้วแก้เองไม่ได้ (เช่น กุญแจบัตร หรือ Mock Login) ให้ส่งให้ IT

> ซ้อมระบบได้ตามสบายด้วยโหมด `MANUAL_OPEN` แต่**ซ้อมเสร็จต้องให้ IT ล้างคะแนนทดสอบ**
> ก่อนวันจริงเสมอ ไม่งั้นคะแนนซ้อมจะปนกับของจริง

## 4. วันเลือกตั้ง

ปกติ **ไม่ต้องทำอะไรเลย** ระบบเปิด-ปิดตามเวลาที่ตั้งไว้

- ดูยอดผู้ใช้สิทธิ์สดที่แท็บ **ภาพรวม**
- ระบบไม่แสดงว่าใครเลือกพรรคไหน — ข้อมูลนั้นไม่มีอยู่ในระบบตั้งแต่แรก ต่อให้เป็นแอดมินก็ดูไม่ได้

**ถ้ามีปัญหา** เช่น เว็บช้ามาก มีคนแจ้งว่าโหวตไม่ได้ หรือพบข้อผิดพลาดในข้อมูลพรรค:

1. สลับโหมดเป็น **`PAUSE`** ทันที — ระบบหยุดรับโหวต บัตรที่ลงไปแล้วปลอดภัย ไม่หาย ไม่ซ้ำ
2. แจ้ง IT พร้อมบอกว่าเกิดตอนไหน อาการอะไร
3. แก้เสร็จแล้วสลับกลับ **`AUTO`**

> อย่าลืมสลับกลับ — ถ้าค้างที่ `PAUSE` นักศึกษาจะโหวตไม่ได้ทั้งวัน

## 5. หลังปิดหีบ

1. **ขอ IT ตรวจคะแนนก่อน** — เขามีคำสั่งตรวจว่าคะแนน จำนวนบัตร และโซ่ตรวจสอบตรงกันทั้งสามทาง
   รอผลยืนยันจากเขาก่อนค่อยทำข้อถัดไป
2. **เปิดสวิตช์ "การแสดงผลคะแนน"** ที่แท็บตั้งค่าระบบ — ทุกคนเห็นผลทันที
3. **แจ้งเจ้าหน้าที่ให้กด "รับรองผล"** — ปุ่มนี้กรรมการสโมฯ กดไม่ได้ ต้องเป็นเจ้าหน้าที่คณะ
   เข้าด้วยบัญชีของเขาเองเท่านั้น เพราะการรับรองผลคือการเซ็นชื่อรับรองการเลือกตั้งของสโมฯ
   ให้คนนอกเป็นคนเซ็นจึงตรวจสอบได้มากกว่า · ระบบจะบันทึกชื่อคนที่กดกับเวลาไว้ และขึ้นบนหน้าผลคะแนน
4. **กดแล้วย้อนกลับไม่ได้** หลังรับรองผล ระบบจะล็อก — เปิดหีบใหม่ไม่ได้ รับคะแนนเพิ่มไม่ได้
   ตรวจให้แน่ก่อนบอกเจ้าหน้าที่ว่าพร้อม
5. ส่งมอบให้กรรมการชุดหน้า ([§7](#7-ส่งมอบ))

> **อยากได้ผลเป็นเอกสารไปแนบรายงาน** — หลังรับรองผลแล้ว เปิดหน้าผลคะแนนแล้วสั่งพิมพ์ (Ctrl+P)
> จะได้หน้าที่มีแถบรับรองพร้อมชื่อผู้รับรองและวันเวลา เมนูกับปุ่มถูกซ่อนให้อัตโนมัติ
> เลือก "บันทึกเป็น PDF" ก็ได้ไฟล์ไปใช้ได้เลย ไม่ต้องขออะไรจาก IT

**ถ้ามีคนตั้งคำถามกับผลคะแนน** — ระบบพิสูจน์ได้ว่าบัตรทุกใบไม่ถูกแก้ไข และถ้าถึงขั้นต้องนับใหม่
ก็ทำได้ต่อหน้ากรรมการ ทั้งสองอย่างเป็นงานของ IT แจ้งเขาได้เลย

## 6. เรื่องที่ต้องขอ IT

สิ่งเหล่านี้ทำในหน้าแอดมินไม่ได้โดยตั้งใจ — ต้องเข้าเซิร์ฟเวอร์ ซึ่งเป็นงานของ IT คณะ

| เรื่อง | บอกเขาว่า | ควรแจ้งล่วงหน้า |
|---|---|---|
| เพิ่มกรรมการเป็นแอดมิน | ขอเพิ่มสิทธิ์แอดมินให้รหัส นศ. …… | 2-3 วัน |
| ถอดสิทธิ์คนที่พ้นวาระ | ขอถอดสิทธิ์แอดมินของรหัส นศ. …… | ทันทีที่พ้นวาระ |
| ลืมรหัสกลาง / รหัสหลุด | ขอออกรหัสกลางใหม่ | ทันที |
| นำเข้ารายชื่อผู้มีสิทธิ์ปีนี้ | ส่งไฟล์รายชื่อให้เขา import | 1 สัปดาห์ |
| ล้างข้อมูลปีเก่า / ล้างคะแนนซ้อม | ขอล้างข้อมูลเพื่อเริ่มปีใหม่ | 1 สัปดาห์ |
| พิธีสร้างกุญแจบัตร | นัดวันกับ IT | 1 สัปดาห์ |
| ปุ่มตรวจความพร้อมขึ้นแดงในข้อที่แก้เองไม่ได้ | ส่งภาพหน้าจอข้อที่แดงให้เขา | ก่อนวันจริง |
| ตรวจคะแนนหลังปิดหีบ | ขอผลการตรวจ reconcile ก่อนประกาศผล | วันปิดหีบ |
| เว็บล่ม / ช้าผิดปกติ | บอกเวลาที่เกิด อาการ และภาพหน้าจอ | ทันที |

**เวลาแจ้ง ให้ข้อมูลสามอย่างเสมอ:** เกิดตอนไหน · กำลังทำอะไรอยู่ · ข้อความบนจอ (ถ่ายรูปมา)

## 7. ส่งมอบ

จบการเลือกตั้งแล้ว ก่อนหมดวาระ:

1. **ขอ IT ถอดสิทธิ์แอดมินของกรรมการชุดคุณทุกคน แล้วออกรหัสกลางใหม่ให้ชุดถัดไป**
   สำคัญ: คนที่พ้นวาระยังจำรหัสเดิมได้ ต้องตัดทั้งสิทธิ์และรหัส
2. ส่งไฟล์นี้ให้กรรมการชุดใหม่ พร้อมบอกว่าใครคือผู้ติดต่อฝั่ง IT
3. ข้อมูลที่กรอกไว้ (พรรค ธีม การตั้งค่า) ยังอยู่ ชุดใหม่แก้ทับได้เลย
