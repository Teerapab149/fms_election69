## 1. เข้าระบบ

`https://ovs.fms.psu.ac.th/admin/login`

```
Username   รหัส นศ. ของตัวเอง       เช่น 6610510149
Password   รหัสกลาง                 20 ตัวอักษรที่ได้จาก IT
```

**ต้องมีครบสองอย่างถึงเข้าได้** — รหัส นศ. ของคุณต้องถูกตั้งเป็นแอดมินไว้ **และ** ต้องรู้รหัสกลาง
รหัสกลางเป็นตัวเดียวกันทั้งชุดกรรมการ แต่ระบบรู้ว่าใครเป็นคนกด เพราะดูจากรหัส นศ. ที่ล็อกอิน

> ⚠️ Password คือรหัสกลางล้วน ๆ ไม่ต้องเอารหัส นศ. หรืออีเมลมาต่อข้างหน้า

**เข้าไม่ได้?**

| อาการ | ทำอะไร |
|---|---|
| ขึ้นว่า "คุณไม่มีสิทธิ์เข้าถึง (สำหรับ Admin เท่านั้น)" | รหัส นศ. คุณยังไม่ถูกตั้งเป็นแอดมิน → ขอ IT ([§6](#6-เรื่องที่ต้องขอ-it)) |
| ขึ้นว่า "ชื่อผู้ใช้งาน หรือ รหัสผ่าน ไม่ถูกต้อง" | รหัสกลางผิด รหัสถูกเปลี่ยนแล้ว หรือรหัส นศ. นี้ไม่มีในระบบเลย (พิมพ์ผิด หรือยังไม่ได้นำเข้า) → ตรวจตัวเลขก่อน ถามคนในทีม แล้วค่อยขอ IT |
| ขึ้นว่า "พยายามเข้าสู่ระบบบ่อยเกินไป ลองใหม่ใน … วินาที" | ระบบกันเดารหัส (ลองได้ 10 ครั้งใน 5 นาที) รอตามจำนวนวินาทีที่ขึ้นแล้วลองใหม่ |
| เข้าได้แต่พออยู่ ๆ ก็เด้งออก | สิทธิ์ถูกถอด หรือครบ 2 ชั่วโมง (ระบบให้ล็อกอินซ้ำทุก 2 ชม.) |

**คนในทีมเพิ่งลาออก / รหัสหลุด** → ขอ IT เปลี่ยนรหัสกลาง ทุกคนจะได้รหัสใหม่พร้อมกัน

> เจ้าหน้าที่คณะที่ทำหน้าที่ **รับรองผล** ([§5](#5-หลังปิดหีบ)) ไม่ได้ใช้รหัสกลาง
> เขามีบัญชีเจ้าหน้าที่ (STAFF) กับรหัสส่วนตัวของเขาเอง ซึ่ง IT เป็นคนออกให้

## 2. หน้าแอดมินมีอะไรบ้าง

แท็บเรียงจากบนลงล่างตามเมนูด้านซ้าย:

| แท็บ | ใช้ทำอะไร |
|---|---|
| **คู่มือใช้งาน** | คู่มือฉบับย่อในตัวเว็บเอง ไล่เป็นระยะ 1-4 อ่านตรงนี้ก็ได้ ไม่ต้องเปิดไฟล์ |
| **ภาพรวม** | ยอดผู้ใช้สิทธิ์แบบสด แยกตามชั้นปี/สาขา/เพศ (บอกแค่ว่ามาใช้สิทธิ์กี่คน ไม่บอกว่าเลือกใคร) และนาฬิกาบอกสถานะหีบ |
| **ตั้งค่าทั่วไป** | ข้อมูลที่ขึ้นบนเว็บ แบ่ง 5 กลุ่ม: `วันเวลาเลือกตั้ง` `ครั้งที่และปี` `ชื่อองค์กรและโครงการ` `แบบประเมินหลังลงคะแนน` (ลิงก์ Google Form กับชั่วโมงกิจกรรม) และ `โปสเตอร์ประชาสัมพันธ์` แก้แล้วกด `บันทึก` |
| **จัดการผู้สมัคร** | เพิ่ม/แก้/ลบพรรคและสมาชิก รูป สี นโยบาย |
| **เลือกธีม (Template)** | หน้าตาเว็บทั้งระบบ แบ่งเป็นกลุ่ม `ทางการ เรียบ` กับ `งานออกแบบ` หลายแบบมีโทนสีให้เลือกเพิ่ม ดูตัวอย่างทุกหน้าก่อนกดใช้ได้ |
| **ตั้งค่าระบบ** | ที่สั่งงานการเลือกตั้งจริง (ดูด้านล่าง) |

**แท็บตั้งค่าระบบ** มีของเรียงจากบนลงล่าง:

1. ป้ายสถานะการเข้าสู่ระบบจำลอง (Mock Login) — ดูอย่างเดียว ถ้าขึ้นว่ายังเปิดอยู่ แจ้ง IT
2. การ์ด `ตรวจความพร้อมระบบ READINESS` กับปุ่ม `ตรวจตอนนี้` ([§3](#3-ก่อนเลือกตั้ง))
3. `ตั้งค่าระบบเลือกตั้ง (System Mode)` — ปุ่มเลือกโหมด 4 ปุ่มในหัวข้อ `ระบบการทำงาน` และคำอธิบาย `แต่ละโหมดใช้ตอนไหน`
4. `ขั้นตอนปิดการเลือกตั้ง` — ปิดหีบ → ประกาศผล → รับรองผล ([§5](#5-หลังปิดหีบ))
5. กล่อง `ขึ้นปีการศึกษาใหม่` — อธิบายว่าการล้างข้อมูลปีเก่าเป็นงานของ IT ไม่มีปุ่มในหน้านี้โดยตั้งใจ

**โหมดระบบ 4 แบบ** (ชื่อบนปุ่มตามที่เห็นบนจอ):

| ปุ่มบนจอ | ความหมาย | ใช้ตอนไหน |
|---|---|---|
| `AUTO (อัตโนมัติ)` | เปิด-ปิดหีบเองตามวันเวลาใน **ตั้งค่าทั่วไป** | **ค่าปกติ ใช้อันนี้** |
| `OPEN (เปิดระบบ)` | บังคับเปิดรับคะแนนทันที ไม่สนวันเวลา | ซ้อมระบบ หรือตั้ง `AUTO` ไว้แล้วระบบไม่เปิดหีบตามเวลา **ไม่ใช่ปุ่มขยายเวลา** (ดูกล่องด้านล่าง) |
| `PAUSE (ระงับ)` | หยุดรับคะแนนชั่วคราว นักศึกษาเห็นหน้าพักระบบ | **ฉุกเฉินวันเลือกตั้ง** แล้วจะกลับมาเปิดต่อ |
| `ENDED (ปิดระบบ)` | ปิดหีบทันที ไม่รับคะแนนอีก | ปิดหีบก่อนเวลาด้วยมติกรรมการ หรือ `AUTO` ไม่ปิดหีบตามเวลา หรือกำลังใช้ `OPEN` อยู่แล้วหมดเวลาเลือกตั้ง |

> ⚠️ **`OPEN (เปิดระบบ)` ไม่ปิดหีบเอง**
> บนจอเขียนไว้ว่า "OPEN จะไม่เปลี่ยนเป็น ENDED เอง แม้เลยเวลาปิดหีบแล้ว เมื่อหมดเวลาเลือกตั้ง ต้องกลับมากด ENDED ด้วยตัวเอง"
> และกล่องยืนยันตอนกด (หัวข้อ `เปลี่ยนเป็น OPEN (เปิดระบบ)?`) บอกว่า
> "หีบจะเปิดทันที ไม่สนวันเวลาที่ตั้งไว้ นักศึกษาที่ยังไม่ได้ลงคะแนนจะลงคะแนนได้ และหีบจะเปิดอยู่จนกว่าจะเปลี่ยนเป็น ENDED แม้เลยเวลาปิดหีบแล้ว"
> (ถ้ากดจาก `PAUSE` หรือ `ENDED` ข้อความจะขึ้นต้นว่า "หีบจะเปิดอีกครั้งทันที")
> - ระหว่างที่อยู่ `OPEN` **ประกาศผลไม่ได้** เพราะหีบยังรับคะแนนอยู่ ต้องกด `ENDED` ก่อน
> - แท็บ **ภาพรวม** จะขึ้นว่า "เปิดรับคะแนนอยู่ (OPEN) ไม่มีเวลาปิด กด ENDED เพื่อปิดหีบ" ถ้าเห็นข้อความนี้หลังเวลาปิดหีบ แปลว่ายังมีคนลงคะแนนได้อยู่
> - **ซ้อมเสร็จห้ามทิ้งไว้ที่ `OPEN`** เปลี่ยนกลับเป็น `AUTO` ทุกครั้ง

**วันเวลาใน ตั้งค่าทั่วไป คือหีบ** — ในโหมด `AUTO` ระบบดูช่อง `เปิดหีบ` กับ `ปิดหีบ` ตลอดเวลา
แก้วันเวลาระหว่างเลือกตั้งได้ แต่ผลจะเกิดทันทีที่กด `บันทึก`:

- เลื่อน `ปิดหีบ` ให้เร็วขึ้นจนเลยเวลาปัจจุบัน → หีบปิดทันที
- เลื่อน `ปิดหีบ` ออกไปหลังจากหีบปิดไปแล้ว → หีบเปิดอีกครั้ง
- ช่อง `เปิดตัวผู้สมัคร` ไม่เกี่ยวกับหีบ แค่บอกว่าหน้ารายชื่อพรรคเริ่มแสดงเมื่อไหร่
- **ต้องการขยายเวลาลงคะแนน → อยู่ที่ `AUTO` แล้วแก้ช่อง `ปิดหีบ`** อย่าใช้ `OPEN` เพราะหีบจะไม่ปิดเองอีกเลย

ถ้าระบบไม่ยอมบันทึกวันเวลา จะขึ้นข้อความอย่างใดอย่างหนึ่งนี้:

| ข้อความ | แปลว่า |
|---|---|
| "เวลาปิดหีบต้องอยู่หลังเวลาเปิดหีบ" | กรอกสลับกัน แก้ให้ปิดหลังเปิด |
| "อ่านวันเวลาเปิดหีบหรือปิดหีบไม่ออก — เลือกวันเวลาใหม่จากช่องในฟอร์ม" | เลือกวันเวลาใหม่จากช่องเลือกวัน อย่าพิมพ์เอง |
| "ผลคะแนนกำลังแสดงอยู่ — ซ่อนผลก่อน แล้วจึงแก้วันเวลาให้หีบเปิดอีกครั้งได้" | ประกาศผลไปแล้ว จะแก้ให้หีบเปิดอีกต้องกด `ซ่อนผล` ก่อน ([§5](#5-หลังปิดหีบ)) |
| "ผลถูกรับรองแล้ว แก้วันเวลาเลือกตั้งไม่ได้" | รับรองผลแล้ว ปิดถาวรสำหรับการเลือกตั้งครั้งนี้ |

ช่องอื่นในแท็บ ตั้งค่าทั่วไป (ชื่องาน ปี ลิงก์ ฯลฯ) บันทึกได้ตลอด ไม่เปิดหรือปิดหีบ

## 3. ก่อนเลือกตั้ง

เริ่มก่อนวันจริงอย่างน้อย 1-2 สัปดาห์

1. **แจ้ง IT ล่วงหน้า** ว่าจะจัดเลือกตั้งเมื่อไหร่ — เขาต้องล้างข้อมูลปีเก่า นำเข้ารายชื่อผู้มีสิทธิ์
   ทำพิธีสร้างกุญแจบัตร และสร้างบัญชีเจ้าหน้าที่สำหรับรับรองผล ([§6](#6-เรื่องที่ต้องขอ-it))
2. **แท็บตั้งค่าทั่วไป** — กรอกทุกกลุ่มให้ครบ โดยเฉพาะ **วันเวลา 3 ช่อง**
   (`เปิดตัวผู้สมัคร` / `เปิดหีบ` / `ปิดหีบ`) เวลาที่กรอกเป็นเวลาไทยเสมอ
   - **ลิงก์ Google Form** ในกลุ่ม `แบบประเมินหลังลงคะแนน`: บนจอเขียนว่า
     "เว้นว่าง = ปีนี้ไม่มีแบบประเมิน ไม่มีปุ่ม และไม่ล็อกหน้าผลคะแนน"
     ถ้าใส่ลิงก์ไว้ ระหว่างที่หีบยังเปิด นักศึกษาที่ลงคะแนนแล้วต้องทำแบบประเมินก่อนถึงจะเข้าหน้าผลคะแนนได้
     ปีไหนไม่มีแบบประเมินก็เว้นว่างได้เลย การตรวจความพร้อมจะแค่ขึ้นเตือน
   - ช่อง `ชั่วโมงกิจกรรม` ใส่เลขเมื่อคณะยืนยันแล้วเท่านั้น ไม่แน่ใจให้เว้นว่าง
3. **แท็บจัดการผู้สมัคร** — กรอกพรรค สมาชิก รูป นโยบาย ให้ครบ **และให้จบก่อนซ้อมระบบ** (ดูข้อควรระวัง ก. ด้านล่าง)
   - ตัวเลือก งดออกเสียง และ ไม่รับรอง ระบบสร้างและลบให้เองตามจำนวนพรรค
     มีพรรคเดียว ระบบจะสลับเป็นบัตร รับรอง / ไม่รับรอง / งดออกเสียง ให้เอง
4. **แท็บเลือกธีม (Template)** — เลือกหน้าตาเว็บของปีนั้น กดดูตัวอย่างก่อนได้
5. **แท็บตั้งค่าระบบ** — โหมด `AUTO (อัตโนมัติ)` และใน `ขั้นตอนปิดการเลือกตั้ง` ยังไม่มีขั้นไหนเสร็จ
   (ขั้น `ปิดหีบ` ขึ้นว่า "หีบยังเปิดรับคะแนนอยู่" ขั้น `ประกาศผล` ขึ้นว่า "ประกาศได้หลังปิดหีบ")
   ไม่ต้องกลัวผลรั่ว ระบบไม่ยอมประกาศผลก่อนหีบปิดอยู่แล้ว
6. **กดปุ่ม `ตรวจตอนนี้`** ในการ์ด `ตรวจความพร้อมระบบ READINESS` เป็นด่านสุดท้าย ระบบเช็คให้เอง 16 ข้อ
   โดยไม่แก้ข้อมูลอะไร
   - ด้านบนมีป้ายสรุป `ไม่ผ่าน` / `เตือน` / `ผ่าน` พร้อมจำนวน ข้อที่ไม่ผ่านขึ้นก่อนเสมอ
     กดป้ายเพื่อดูเฉพาะระดับนั้น กดซ้ำเพื่อกลับมาดูทั้งหมด
   - **ต้องไม่มีข้อ `ไม่ผ่าน` (สีแดง)** ข้อ `เตือน` (สีเหลือง) อ่านให้แน่ใจว่ารู้แล้วและตั้งใจ
   - ถ้าข้อ "ตัวเลือกกรณีพรรคเดียว" ไม่ผ่าน จะมีปุ่ม `สร้างตัวเลือกที่ขาดให้อัตโนมัติ` อยู่ใต้ข้อนั้น กดได้เลย
   - ข้อต่อไปนี้กรรมการแก้เองไม่ได้ ถ้าแดงหรือเหลืองให้ส่งภาพหน้าจอให้ IT:
     "การเข้าสู่ระบบจำลอง (Mock Login)" "โฟลเดอร์เก็บรูปที่อัปโหลด" "สำรองข้อมูลอัตโนมัติ (backup)"
     "รายชื่อผู้มีสิทธิ์เลือกตั้ง" และ "ความสอดคล้องของคะแนน"
   - "โฟลเดอร์เก็บรูปที่อัปโหลด" ขึ้นเหลืองได้ตั้งแต่ติดตั้งครั้งแรก แจ้ง IT ไว้ ไม่ใช่เรื่องฉุกเฉิน
     แต่ถ้าแดง แปลว่าอัปโหลดรูปไม่ได้เลย ต้องแจ้งทันที

**ซ้อมระบบ** — ทำได้ด้วยโหมด `OPEN (เปิดระบบ)` แล้วกลับมาที่ `AUTO (อัตโนมัติ)` และ
**ซ้อมเสร็จต้องให้ IT ล้างคะแนนทดสอบ** ก่อนวันจริงเสมอ ([STAFF-IT-GUIDE §5](STAFF-IT-GUIDE.md#annual-reset))
ไม่งั้นคะแนนซ้อมจะปนกับของจริง ระหว่างซ้อมมีสามเรื่องที่ต้องระวัง:

> **ก. บัตรใบแรกล็อกโครงสร้างบัตร** — พอมีบัตรในระบบแม้แต่ใบเดียว (รวมบัตรซ้อม)
> จะเพิ่มพรรค ลบพรรค หรือเปลี่ยนหมายเลขพรรคไม่ได้อีก ระบบจะขึ้นว่า
> "มีบัตรลงคะแนนในระบบแล้ว … ใบ จึงเพิ่มพรรคใหม่ไม่ได้ — การแก้โครงสร้างบัตรกลางคันทำให้ผลนับไม่ตรง"
> (หรือ "จึงลบพรรคไม่ได้" / "จึงเปลี่ยนหมายเลขพรรคไม่ได้") แก้สโลแกน รูป นโยบาย ยังทำได้ตามปกติ
> จึงควรใส่พรรคให้ครบก่อนซ้อม ถ้าซ้อมไปแล้วต้องให้ IT ล้างคะแนนซ้อมก่อนถึงจะแก้ได้
>
> **ข. ห้ามกด `รับรองผล` ตอนซ้อม** — รับรองแล้วเปลี่ยนโหมดได้แค่ `ENDED` อย่างเดียว
> แก้วันเวลาไม่ได้ และย้อนกลับเองไม่ได้ ต้องให้ IT ปลดให้ ([STAFF-IT-GUIDE §5](STAFF-IT-GUIDE.md#annual-reset))
>
> **ค. ถ้าซ้อมจนถึงประกาศผล ต้องกด `ซ่อนผล` ก่อนสลับโหมดกลับ** — ไม่งั้นปุ่มโหมดอื่นจะกดไม่ได้
> และขึ้นว่า "ผลคะแนนกำลังแสดงอยู่ — ปิดการแสดงผลก่อน แล้วจึงเปิดหีบหรือพักระบบได้"

## 4. วันเลือกตั้ง

ปกติ **ไม่ต้องทำอะไรเลย** ระบบเปิด-ปิดตามเวลาที่ตั้งไว้

- ดูยอดผู้ใช้สิทธิ์สดที่แท็บ **ภาพรวม**
- ระบบไม่แสดงว่าใครเลือกพรรคไหน — ข้อมูลนั้นไม่มีอยู่ในระบบตั้งแต่แรก ต่อให้เป็นแอดมินก็ดูไม่ได้
- อยากขยายเวลา ให้แก้ช่อง `ปิดหีบ` ในแท็บ ตั้งค่าทั่วไป ตามที่อธิบายใน [§2](#2-หน้าแอดมินมีอะไรบ้าง) อย่าใช้ `OPEN`

**ถ้ามีปัญหา** เช่น เว็บช้ามาก มีคนแจ้งว่าโหวตไม่ได้ หรือพบข้อผิดพลาดในข้อมูลพรรค:

1. สลับโหมดเป็น **`PAUSE (ระงับ)`** ทันที — กล่องยืนยันจะบอกว่า
   "หยุดรับคะแนนชั่วคราว นักศึกษาจะเห็นหน้าพักระบบ และลงคะแนนไม่ได้จนกว่าจะเปลี่ยนโหมดกลับ"
   บัตรที่ลงไปแล้วปลอดภัย ไม่หาย ไม่ซ้ำ
   ระหว่างนี้หน้าเว็บฝั่งนักศึกษาขึ้นข้อความพักระบบ (เช่น "หยุดรับคะแนนชั่วคราว" หรือ "พักระบบชั่วคราว" แล้วแต่ธีม)
   และแท็บ **ภาพรวม** ขึ้นว่า "หยุดรับคะแนนชั่วคราว"
2. แจ้ง IT พร้อมบอกว่าเกิดตอนไหน อาการอะไร
3. แก้เสร็จแล้วสลับกลับ **`AUTO (อัตโนมัติ)`**
   ถ้ากลับมาตอนเลยเวลาปิดหีบไปแล้ว กล่องยืนยันจะบอกว่า "เลยเวลาปิดหีบแล้ว หีบจะยังปิดอยู่ตามกำหนดการ"
   ถ้าต้องการเวลาเพิ่มเพื่อชดเชยช่วงที่พัก ให้แก้ช่อง `ปิดหีบ` ก่อนแล้วค่อยกลับเป็น `AUTO`

> อย่าลืมสลับกลับ — ถ้าค้างที่ `PAUSE` นักศึกษาจะโหวตไม่ได้ทั้งวัน
> และ **`PAUSE` ไม่ใช่การปิดหีบ** ระหว่าง `PAUSE` ประกาศผลไม่ได้ จะจบการเลือกตั้งต้องใช้ `ENDED`

## 5. หลังปิดหีบ

ทุกอย่างอยู่ในหัวข้อ `ขั้นตอนปิดการเลือกตั้ง` ในแท็บตั้งค่าระบบ
บนจอเขียนว่า "ทำตามลำดับ ปุ่มของขั้นถัดไปจะกดได้เมื่อขั้นก่อนหน้าเสร็จแล้ว" มีสามขั้น:

**ขั้นที่ 1 `ปิดหีบ`**

- ในโหมด `AUTO` หีบ **ปิดเอง** เมื่อถึงเวลาปิดหีบ ไม่ต้องกดอะไร ขั้นนี้จะขึ้นว่า "ปิดตามเวลา …" แล้วเป็นเสร็จ
- ถ้าใช้ `OPEN` อยู่ หรือกรรมการมีมติปิดก่อนเวลา กดปุ่ม `ปิดหีบตอนนี้ (ENDED)`
  กล่องยืนยัน `เปลี่ยนเป็น ENDED (ปิดระบบ)?` บอกว่า
  "ปิดหีบทันที ไม่รับคะแนนอีก ผลคะแนนยังไม่แสดงจนกว่าจะเปิดการแสดงผล"
  เสร็จแล้วขั้นนี้ขึ้นว่า "ปิดด้วยโหมด ENDED"
- ปิดหีบแล้วยังไม่มีใครเห็นคะแนนรายพรรค รวมถึงแอดมินเอง จนกว่าจะประกาศผล

**ขั้นที่ 2 `ประกาศผล`**

- กดปุ่ม `ประกาศผล` (กดได้หลังปิดหีบเท่านั้น ก่อนหน้านั้นปุ่มจาง และขึ้นว่า "ประกาศได้หลังปิดหีบแล้วเท่านั้น")
  กล่องยืนยัน `ประกาศผลคะแนน?` บอกว่า
  "ทุกคนจะเห็นคะแนนรายพรรคและสถิติผู้ใช้สิทธิ์ที่หน้าผลคะแนนทันที เมื่อประกาศแล้ว จะเปิดหีบอีกไม่ได้จนกว่าจะซ่อนผลก่อน"
  สำเร็จแล้วขึ้นว่า "เปิดแสดงผลคะแนนแล้ว ทุกคนดูผลได้ที่หน้าผลคะแนน"
- **หน้าผลคะแนนที่นักศึกษาเปิดค้างไว้จะเปลี่ยนเป็นผลเองภายในไม่กี่วินาที** ไม่ต้องบอกให้ใครกดรีเฟรช
- ถ้าระบบตอบว่า "ยังเปิดแสดงผลไม่ได้ — หีบยังไม่ปิด เปลี่ยนเป็น ENDED หรือรอให้เลยเวลาปิดหีบก่อน แล้วค่อยเปิดแสดงผล"
  แปลว่าหีบยังรับคะแนนได้อยู่ (มักเป็นเพราะค้างที่ `OPEN` หรือ `PAUSE`) กลับไปทำขั้นที่ 1 ก่อน
- ระหว่างที่ผลแสดงอยู่ ใต้ปุ่มโหมดจะขึ้นว่า
  "ผลคะแนนกำลังแสดงอยู่ จึงเปิดหีบหรือพักระบบไม่ได้ ถ้าต้องเปิดหีบอีกครั้ง ให้ปิดการแสดงผลก่อน"
- **ประกาศผิดจังหวะ หรือต้องเปิดหีบอีกครั้ง** — ในขั้นนี้มีปุ่ม `ซ่อนผล` (มีเฉพาะตอนผลแสดงอยู่และยังไม่ได้รับรองผล)
  กล่องยืนยัน `ซ่อนผลคะแนน?` บอกว่า
  "เมื่อซ่อนผลคะแนน คะแนนของแต่ละพรรคจะถูกปิดจากทุกคนรวมถึงแอดมินเอง ความคืบหน้าการใช้สิทธิ์ในแท็บภาพรวมยังดูได้ตามปกติ"
  หลังรับรองผลแล้วปุ่มนี้หายไป และระบบไม่ยอมซ่อน
  ("ผลถูกรับรองแล้ว ซ่อนผลไม่ได้ — ผลที่รับรองแล้วต้องแสดงต่อสาธารณะ")

**ขั้นที่ 3 `รับรองผลอย่างเป็นทางการ`** (มีป้าย `ไม่บังคับ`)

- ปุ่ม `รับรองผล` **กรรมการสโมฯ กดไม่ได้** ต้องเป็นเจ้าหน้าที่คณะเข้าด้วยบัญชีเจ้าหน้าที่ของเขาเองเท่านั้น
  เพราะการรับรองผลคือการเซ็นชื่อรับรองการเลือกตั้งของสโมฯ ให้คนนอกเป็นคนเซ็นจึงตรวจสอบได้มากกว่า
  ถ้ากรรมการเผลอกด จะขึ้น `ดำเนินการไม่สำเร็จ (403)` กับข้อความ
  "รับรองผลได้เฉพาะบัญชีเจ้าหน้าที่คณะเท่านั้น — ให้เจ้าหน้าที่เข้าสู่ระบบด้วยบัญชีของตนเองแล้วกดรับรอง"
  ไม่มีอะไรเสียหาย
- กดได้หลังประกาศผลแล้วเท่านั้น (ก่อนนั้นปุ่มจาง และขึ้นว่า "ต้องประกาศผลก่อน")
  ถ้าระบบตอบว่า "ทำได้เฉพาะหลังปิดหีบและเผยแพร่ผลแล้วเท่านั้น" ให้กลับไปทำขั้นที่ 1-2 ให้เสร็จ
- **ก่อนบอกเจ้าหน้าที่ว่าพร้อม แนะนำให้ขอ IT ตรวจคะแนน (reconcile) ก่อน** ตามขั้นตอนใน
  [STAFF-IT-GUIDE §4.3](STAFF-IT-GUIDE.md#43-ตรวจคะแนนและรับรองผล) — บนจอไม่มีขั้นนี้ เป็นเรื่องที่ตกลงกับ IT เอง
- กล่องยืนยัน `รับรองผลอย่างเป็นทางการ?` ของเจ้าหน้าที่จะลงท้ายว่า "กดแล้วย้อนกลับไม่ได้"
  การรับรองไม่ลบข้อมูลอะไร ระบบบันทึกชื่อคนที่กดกับเวลาไว้ และขึ้นเป็นแถบรับรองบนหน้าผลคะแนน
- **หลังรับรองผล ระบบจะล็อก** — เปลี่ยนโหมดได้แค่ `ENDED`
  (ปุ่มอื่นจางและขึ้นว่า "ผลถูกรับรองแล้ว เปลี่ยนโหมดไม่ได้ — การเลือกตั้งครั้งนี้ปิดอย่างเป็นทางการ")
  เปิดหีบใหม่ไม่ได้ รับคะแนนเพิ่มไม่ได้ แก้วันเวลาไม่ได้ เพิ่ม/ลบ/เปลี่ยนหมายเลขพรรคไม่ได้ และซ่อนผลไม่ได้
  ตรวจให้แน่ก่อนบอกเจ้าหน้าที่ว่าพร้อม

สุดท้าย ส่งมอบให้กรรมการชุดหน้า ([§7](#7-ส่งมอบ))

> **อยากได้ผลเป็นเอกสารไปแนบรายงาน** — เปิดหน้าผลคะแนนแล้วสั่งพิมพ์ (Ctrl+P)
> ถ้ารับรองผลแล้ว จะได้หน้าที่มีแถบรับรองพร้อมชื่อผู้รับรองและวันเวลา เมนูกับปุ่มถูกซ่อนให้อัตโนมัติ
> เลือก "บันทึกเป็น PDF" ก็ได้ไฟล์ไปใช้ได้เลย ไม่ต้องขออะไรจาก IT

**ถ้ามีคนตั้งคำถามกับผลคะแนน** — ระบบพิสูจน์ได้ว่าบัตรทุกใบไม่ถูกแก้ไข และถ้าถึงขั้นต้องนับใหม่
ก็ทำได้ต่อหน้ากรรมการ ทั้งสองอย่างเป็นงานของ IT แจ้งเขาได้เลย ([STAFF-IT-GUIDE §4.3](STAFF-IT-GUIDE.md#43-ตรวจคะแนนและรับรองผล))

ขั้นตอนฝั่งเขาอยู่ในหัวข้อที่ลิงก์ไว้ ไม่ต้องอ่านเอง แค่บอกเขาว่าเป็นหัวข้อไหน

| ลืมรหัสกลาง / รหัสหลุด | ขอออกรหัสกลางใหม่ ([§4.1](STAFF-IT-GUIDE.md#41-บัญชีเจ้าหน้าที่และกรรมการ)) | ทันที |

| ข้อ "สำรองข้อมูลอัตโนมัติ (backup)" ขึ้นเหลืองหรือแดง | ส่งภาพหน้าจอข้อนั้น ระบบควรสำรองเองทุก 6 ชั่วโมง ([§6.1](STAFF-IT-GUIDE.md#61-สำรองข้อมูล)) | ทันที (แดง) / วันทำการถัดไป (เหลือง) |
| ข้อ "โฟลเดอร์เก็บรูปที่อัปโหลด" ขึ้นแดง หรืออัปโหลดรูปไม่ได้ / รูปหาย | ส่งภาพหน้าจอ ([§7.2](STAFF-IT-GUIDE.md#72-อัปโหลดรูปไม่ได้บน-linux) [§7.3](STAFF-IT-GUIDE.md#73-รูปที่อัปโหลดหายหรือขึ้นเป็นช่องว่าง)) | ทันที |
| ตรวจคะแนนหลังปิดหีบ | ขอผลการตรวจ reconcile ก่อนเจ้าหน้าที่รับรองผล ([§4.3](STAFF-IT-GUIDE.md#43-ตรวจคะแนนและรับรองผล)) | วันปิดหีบ |
| เว็บล่ม / ช้าผิดปกติ | บอกเวลาที่เกิด อาการ และภาพหน้าจอ | ทันที |

**เวลาแจ้ง ให้ข้อมูลสามอย่างเสมอ:** เกิดตอนไหน กำลังทำอะไรอยู่ และข้อความบนจอ (ถ่ายรูปมา)

## 7. ส่งมอบ

จบการเลือกตั้งแล้ว ก่อนหมดวาระ:

1. **ขอ IT ถอดสิทธิ์แอดมินของกรรมการชุดคุณทุกคน แล้วออกรหัสกลางใหม่ให้ชุดถัดไป**
   สำคัญ: คนที่พ้นวาระยังจำรหัสเดิมได้ ต้องตัดทั้งสิทธิ์และรหัส
2. ส่งไฟล์นี้ให้กรรมการชุดใหม่ พร้อมบอกว่าใครคือผู้ติดต่อฝั่ง IT
3. ข้อมูลที่กรอกไว้ (พรรค ธีม การตั้งค่า) ยังอยู่ ชุดใหม่แก้ทับได้เลย
