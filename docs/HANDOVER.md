# เอกสารส่งมอบ FMS Online Voting System (FMS-OVS)

ใช้ประกอบการส่งมอบระบบเลือกตั้งออนไลน์ให้คณะวิทยาการจัดการ ม.อ. เขียนเมื่อ 2026-11-15
บอกว่าส่งมอบอะไร ใครต้องถืออะไร ระบบยังมีข้อจำกัดอะไร และคณะต้องตัดสินใจเรื่องใดก่อนใช้งาน

ช่องที่เขียนว่า **[เจ้าของกรอก]** เป็นเรื่องธุรกิจหรือกฎหมายที่ผู้พัฒนาต้องกรอกเองก่อนส่ง เอกสารนี้ไม่ได้กำหนดแทน

## 3. ข้อจำกัดที่รู้แล้ว

| F4 | ประกาศผลกลางวันแล้วเปิดหีบต่อ | **แก้แล้ว** |
| F5 | ระบุตัวเลือกผู้ลงคะแนนจากฐานข้อมูลโดยไม่ใช้กุญแจ | **บางส่วน** เส้น B แก้แล้ว เส้นอื่นยังอยู่สำหรับผู้ที่อ่านฐานข้อมูลได้ก่อนรับรองผล จึงต้องจำกัดผู้เข้าถึงฐานข้อมูลระหว่างเปิดหีบ |

| npm audit | ช่องโหว่ในแพ็กเกจ | เหลือ 7 รายการในแพ็กเกจที่ไม่ใช่ dev ทุกตัวต้องขึ้นรุ่นหลัก ประเมินแล้วว่าไม่ถึงตอนรันจริง ควรอัปเกรด next และ prisma ในช่วงที่ไม่มีการเลือกตั้ง |

## 6. การตรวจรับ

ตรวจรับเมื่อทำครบทุกข้อ และบันทึกผลพร้อมรหัส commit ที่ติดตั้ง:

1. ติดตั้งและตรวจตาม [DEPLOY-CHECKLIST-2026.md](DEPLOY-CHECKLIST-2026.md) ข้อ 0 ถึง 12
2. หน้าแอดมิน เมนู ความพร้อมและระบบ การ์ด ตรวจความพร้อมระบบ ไม่มีข้อสีแดง ข้อเหลืองทุกข้อมีคำอธิบาย
3. ซ้อมตามเช็คลิสต์ข้อ 13 รวมการรับรองผลด้วยผลนับซ้ำ แล้วล้างข้อมูลซ้อมด้วย `annual-reset.sql`
4. ทดลองกู้ backup ใส่ฐานข้อมูลแยกสำเร็จ ([STAFF-IT-GUIDE §6.3](STAFF-IT-GUIDE.md))
5. กรอกตารางในหัวข้อ 2 และตัดสินเรื่องในหัวข้อ 4 ครบ

ผลตรวจในเครื่องพัฒนา ณ วันเขียนเอกสาร: CI ของ `main` ผ่านทั้ง unit test, build และ e2e, unit test 279 ข้อผ่านทั้งหมด,
e2e ชุดรับรองผลและซ้อมระบบผ่าน 15 ข้อบนฐานข้อมูลในเครื่อง, หน้าตัวอย่าง 12 ธีมหลัก × 7 หน้าโหลดฟอนต์ครบ
**ยังไม่ได้ทดสอบบนเครื่องจริงของคณะ**
