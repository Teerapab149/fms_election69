# Preview-only illustrations

Original geometric SVG artwork created for this project's fictional preview data.
20 avatars, two fictional logos and three team/activity illustrations; no external
images, real likenesses, embedded scripts or external resources.

Do not use this directory for admin uploads. The shared fixtures in
`src/utils/templatePreviewMocks.js` reference these stable paths. Main and modal
portraits intentionally use the same avatar; neither references real members.

The preview parties, identities and social URLs are fictional. Social URLs use
the reserved `.invalid` domain and are not real accounts. These records must
never be seeded or persisted when applying a template.
